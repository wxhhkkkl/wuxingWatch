## 二、7 大根因详解（含代码定位）

### 根因① 同柱生克 / 天干生克泄力未进入旺度总量（最大根因，约 19 条）

**现状**：`wangdu.py` 裁定 **C13**——"天干生克增减力（§2.2 比例）只用于生克权/争合/格局判定，不进入五行度数总量（书中全部数值算例均以此口径呈现）"。`_wx_degrees` 只统计 天干度数 + 藏干通根，干支同柱之间、天干相邻之间 **不产生度数增减**（合绊除外）。

**老师反复指出的证据**（书在这些命例里明确把生克泄力算进度数）：
- [10] 坤丙寅乙未己未甲子：书"日主身旺"，靠的是未中火生己土（同柱）；引擎因甲己合绊把己日主减 5 成 + 无火生土 → 己 7.0 偏弱。
- [352] 坤丁未己酉庚子壬午：书"日主 8 度偏弱"，引擎 12 偏旺；只有 庚生子水（同柱泄）才能把 12 降到 8。
- [293] 书"丑土之力尽泄于辛金……午火被丑害无力生身 → 从弱"；引擎 戊12 偏旺正格。
- [340] 戊坐寅被木克（同柱克）→ 书 从弱；引擎 2.4 比弱正格。
- [208] 辛克乙 + 乙坐丑耗 + 乙克戊 → 书"身较旺不从"；引擎 木28 从强。
- [192] 癸水生甲木 → 书 从弱；引擎水 static=final=2.4 不动。
- [169] 庚寅同柱庚克甲木耗 → 书"日主中和"；引擎 15 较旺。
- [202] 土生金 → 书"从强以辰生申论"；引擎 24 比旺正格。
- [243][108] 火生土（己巳/己未同柱）→ 书 身弱（不从）/身强；引擎偏弱/弱。
- [328] 辰酉合金后金生水 → 书"身较旺"；引擎 9.75 中和。
- [321][327][345] 老师："加同柱生克后再计算/验证"。

**我的建议**：**值得做，且是整批 nomatch 里单项收益最大的一处**。但要作为**专项批次**实施，理由：
1. 书确实在大量命例按"同柱/天干生克泄力进总量"推演，C13 裁定把话说死了，与实际书例矛盾。
2. **重大风险**：现有 111 个 MATCH 锚点（含 §13 的 10 个数字锚点，如 [27] 书 7.5×1.5 无生克项）都是按 C13 标定的。若全局放开，锚点会成片漂移，需要对拍表逐条人工裁决"书此处到底算没算生克"。
3. **实施路径建议**：
   - 第一步只做**同柱生克**（书 §2.1-3 有明文规则"干支之间只有同柱论生克"，范围明确）：对每柱 干支之间 按 §2.2 量化（同性生 ×0.7/×1.3、克 ×0.7/×0.5 等），只改日主/该五行度数。先以 [352][340][10][293][208] 为新锚点。
   - 第二步再评估**相邻天干生克泄力**进总量（争议更大、影响锚点更多）：[192][202][293][308][328] 依赖此条。建议先只让"泄"（主生方减）进总量、"受生方增"先不动，观察对拍表。
   - 每步后全量跑 361 例对拍 + pytest + vitest，MATCH 率可以接受一定回摆（书本身自相矛盾），但**方向性错误（该旺判弱、该从判正）必须清零**。

### 根因② 从格判定缺"根气/实质帮扶"语义 + 无从印/从杀/从财细分（约 16 条）

**现状**：`_judge_geju` 的从弱/从强是纯数值门：
- 从弱 = 日主 <2.4 **且 印 <4 且 比劫 <4**；
- 从强 = 日主 ≥26 **且 克泄耗三方全部 <4**。
既不查"日主是否通根"，也不区分从印/从杀/从财。

**由此产生的两类错误**：

**A. "印一强就不让从" → 把应从的判成正格**（印/比劫数值强但实际不能真正帮扶）：
- [170] 乙2.1 太弱，印水6.4 → 引擎正格；书/师：从弱。
- [176] 甲0.5 弱极，印水7.5 → 正格；书/师：从弱。
- [195] 庚0.5 弱极，印土18 → 正格；书/师：从弱（午戌化火庚无根）。
- [346] 癸0.4 弱极，印金4.2 → 正格；书/师：从弱。
- [133] 戊1.0 太弱，印火19.5 → 正格；书/师：从弱。
- [263] 癸1.0，引擎当前已是**从弱** ✓（老师所述为修复前旧版）。
- [355] 庚1.6 **有申根** → 书/师：**不从**（正格身弱，用辰土）→ 说明从弱必须查根气。

**B. 从印/从杀/从财不区分**（引擎一律从弱"取克泄耗最旺"，书从印取印、从杀取官杀）：
- [184] 丁3.0、印木30 → 书 从印；引擎 正格用火。
- [204] 丙0.92、印木44 → 书 从印；引擎 正格用火。
- [322] 己4.5、印火57 → 书 从印；引擎 正格用土。
- [347] 甲1.5、印水38 → 书 从印；引擎 正格用木。
- [300] 甲6.0、水30 → 书 从印（水印）＋ 子未害未中木根反克；引擎 正格用神水（用神竟与从印"金水为用"一致，仅格局名/喜忌差）。
- [270] 甲0.7、土36 → 书 从财；引擎 正格（印水6.4 藏丑不透判为帮扶）。
- [213] 戊1.0、木50 → 书 从杀；引擎 从弱（用神木恰好=官杀，差异在命名与喜忌）。
- [247] 己15、书"从强之象"（丑午害去丑中金→庚不独立）→ 引擎 正格。
- [72][73] 燥土局 书"从强/低水平从强" → 引擎 正格。

**我的建议**：重写 `_judge_geju`，核心引入**根气检查**（日主有无有效同类通根：有根且未被刑冲合化去 → 正格身弱；无根 + 太弱(<4.0 左右) → 从弱），并细分从印/从杀/从财：
- **从印** = 印星为全局绝对主导（印 ≥ 太旺档）且日主太弱无根；用神=印，喜=生印之行，忌=克印之行。
- **从杀** = 官杀绝对主导；**从财** = 财绝对主导。
- 从强判定的"克泄耗不能独立"也要加根气语义（书[317]"申金可以独立故不从强"——注意老师对 [317] 的判读是**引擎从强正确、书错**，所以这条只作反例说明口径难，不据此改 [317]）。
- 锚点：用 [355]（有根不从）、[259]（刑掉根→从）、[184][204][322][347]（从印）、[270]（从财）写失败测试。
- 注意 [247][72][73] 还叠加"书在日主 15/18/30 度即判从强"，与引擎 ≥26 门不符——书在此处是"气势成专旺"口径，是否按 26 收紧需你拍板（建议保持 ≥26，仅在这几个燥土/火土专旺例上用"燥土从火 + 从印势"特判，见根因③/⑦）。

### 根因③ 地支作用结果未传导到天干合化判定（月令优先、先地支后干）

**现状**：`compute_wangdu` 顺序是 **shengke（天干）步在 zhichong（地支）步之前**；天干合化的"月令旺相""坐支"条件用的是**原始月令**，不知道地支合化已把月令/坐支改成什么。

**老师明确的顺序原则**："先确定月令合，再讨论天干。月令优先。"

**证据**：
- [99] 乾甲寅乙亥丙子辛卯：寅亥合化木成功 → 月令亥**变木** → 丙辛合水应**不化**（月令水不再旺相）。引擎两条都判成功：寅亥化木 ✓ + 丙辛化水 ✓ → 化格（化水）。**顺序错。**
- [112] 坤己未己巳戊寅癸丑：寅巳相刑 → 寅木化成火海 → 戊坐寅=坐支有火 → 戊癸合化火应成功（书"格成化气格"）。引擎未传导 → 正格用神水。
- [117] 坤丁未壬寅丁卯辛亥：亥卯未三合化木成功 → 未变木 → 月日丁壬坐支均木 → 争合"势均力敌" → 不化 → 从印。引擎因木 22<26 判三合不化，争合逻辑没走到。**（其中还含三合化神阈值问题，见根因⑤）**

**我的建议**：调整 `compute_wangdu` 步序——**地支刑冲合害先行、天干合化后行**，天干合化的月令旺相用"地支作用后的月令五行"，坐支用"地支作用后的坐支五行"。这是书"月令优先"的正解，且只影响合化类分支，风险可控。锚点：[99]（丙辛不化）、[112]（戊癸化火→化格）、[117]（从印）。

### 根因⑤ 合化细节条件缺失（子丑化水 / 寅亥水倍 / 辰酉绊多支 / 巳酉绊多支 / 三合绊减力表 / 半合相生度数）

1. **[121][123] 子丑合化水**：根因是 **丑月水状态**。reference §1.2 把丑月水标"余气"（引擎据此化土），但书算例多次按丑月水=**相**（报告 B-4 已自证 reference 自相矛盾）。丑月水改相 → 子丑合化水成立（书[121]水太旺当令化水 → 从弱）。**修复点：`month_state` 丑月水 → 相**（先核对 B-4 全书口径再定）。
2. **[128] 寅亥合化木缺"亥水 < 寅木 3 倍"条件 + 当令双倍**：书"两亥（当令=四亥）合一寅，亥水是寅木 5 倍 → 不化，寅被绊不能为根 → 从印"。引擎直接化木成功。**修复点：`_liuhe_verdict` 寅亥分支补 条件③（亥水<3倍寅木）与 当令翻倍**。
3. **[137] 辰酉合绊多支表**：书"3 辰当令=6 辰合绊 1 酉 → 酉力变 0，每辰乙戊各 −0.2"。引擎走"相生（不化）：酉+1、辰−1、辰中乙减半"——**方向完全相反**。另注意引擎在此例还误触**三辰自刑**（书此例不论自刑），需与辰酉合绊的优先级一起核对。**修复点：`_liuhe_ban_effect` 辰酉分支补 ≥5 辰→酉归零表**。
