## 一、011 规则要点（相对 010 C21 的变化）

| 项 | 010（C21，2026-08-22） | 011（C24，2026-09-03） |
|---|---|---|
| 从强 | 日主≥26 且 克泄耗三方 final<4.0 | 日主≥26 且 克泄耗三方 **各<2.4** 且**不[透干且有字面根]**（严格字面，弱星透干+残根也挡） |
| 从印 | 印≥26、印透干(R4)、日主<8.8 | 印≥26、**日主<2.4**、比劫星(除日主干)/财/食伤各<2.4 且不[透干+字面根]；日主根——阳干字面无根 / 阴干根被 冲刑合 削弱残余<2.4；**删 R4 透干** |
| 从弱前置1 | 根≥1.0(含余气)计算根 | 阳干**字面见根即不从**（刑冲破害不除字面）；阴干 字面根须被刑冲破害削弱至残余<2.4 |
| 从弱前置2 | 紧贴(月/时干)印比有根≥2.0 → 不从 | 印透干 ⇒ 印不得有任何字面根（余气也算） |
| 从弱从神 | 从弱=日主<2.4 无根无帮扶；从印/杀/财 见 010 列 | 从神∈{食伤,财,官杀} **≥26 且禁令清单干净**取最强者；无 ≥26 从神 → 不从弱（正格） |
| 根气判据 | 有效根（藏同类≥阈值 + 合绊去根） | **合化成功支作废**；其余一律字面藏干（含余气），合绊/刑冲不除根 |
| 比劫门 | 未独立成门 | 数值门**不含日主本干**；比劫透干排除日主柱 |

## 三、翻转类别规律（供 361 全量重算预期）

1. **从弱大面 → 正格**：书/师许多"弱极应从"例，克泄耗从神不足 26（多为 10~22）→ 011 需从神≥26 才从 → 正格。
2. **阳干从弱几乎全灭**：字面见日主同类藏干（含余气、含被刑冲/合绊者）即不从。
3. **从印需日主<2.4**：日主比弱（2.4~8.8）而印≥26 的从印例全翻正格。
4. **从强严格字面透干根否决**：日主≥26 但克泄耗弱星透干且藏干字面有根（如 财戊/癸透+库支根）→ 不从强。

> 注：书例中 `从格命例-书引擎对照-20260822.md` 的「引擎(当前)」列基于 010 C21；011 起该列失效，以上表为准，全量 361 重算可复用本引擎（`compute_wangdu`）。
