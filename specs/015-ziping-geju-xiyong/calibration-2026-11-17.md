- 反馈源：`doc/geju-faceoff-review.json`（明达 / 保强 100 例 + 最终裁定）
- 对照：`doc/geju-faceoff-review.json` 的 `decision` / `note`，书例四柱与书判来自
  `D:/tmp/ziping/review/dataset.json`
- 口径：只校准**主格（大格）**；成破、用神、喜忌不在本次改动内。
- 目标格取法：
  - `共识`：两位老师一致的那一方（书 / 引擎）
  - `按书` / `按引擎`：直接取该方
  - `按明达` / `按保强`：若其 `review` 是「同意书/同意引擎」取该方，否则取 `note` 的第三方案
  - `第三方案`：取 `note`
  - `未裁定`：不计入

归类：

1. **阳刃 / 禄劫分类**（062、066、067、075）：引擎与书一致，反馈按「月劫」称之；属术语层级，
   不建议为对齐 note 改大格。
2. **食神 / 伤官去留**（078、079、091）：未月戊/己、巳月丙/丁同类透干时，书内本身存在两套
   取法（对照 D 组 gold-046），暂列 open。
3. **印格 vs 财/七煞**（025、052、060）：印不透或仅会局时，是否以印立格，书内多解。
4. **从格 / 专旺门槛**（040、069）：反馈对「比劫透能否从」「炎上是否成立」本身分歧。
5. **反馈数据自相矛盾**（002、019）：`review` 与 `note` 指向不同格；建议回问保强，确认后
   再决定是否把「印格 / 食神格」作为目标。
6. **格名归属**（038、049）：同一命例书与第三人使用不同大格名，非计算错误。
