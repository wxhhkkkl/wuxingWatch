**确认事项（2026-10-28，使用者）**：① **49 格全量**一次交付（内 27 + 外 22）；② 身强弱分界取**中和 10 度**（日主组动态旺度 ≥10 为身强，<10 为身弱）；③ 本期含**原局 + 大运**（格名以原局为基准、允许按书变格；身强弱按该步引擎2 旺度重取，输出行运喜忌），**流年 / 流月 / 流日 / 流时排除**。

**术语对照（书 → 产品）**：规则与格名用书中原词，界面同时标注产品常用名；对照表随规则表维护。

| 书中 | 产品常用 | 处理 |
|---|---|---|
| 七煞 | 七杀 | 格名/规则用「七煞」，界面标「七杀」 |
| 阳刃 | 羊刃 | 格名/规则用「阳刃」，界面标「羊刃」 |
| 印绶 / 印格 | 正印 / 偏印 | 格名用「印格」，十神仍按正印 / 偏印 |
| 枭印 / 枭神 | 偏印 | 书中用枭印时，界面标「偏印」 |
| 财格 / 官格 | 正财 / 偏财 / 正官 | 格名沿用书的大格名，十神细分按产品 |

**与现有产品的关系**：

- 现有**旺度引擎**（原局旺度 + 大运引擎2）**保留不动**。它对本引擎的唯一职责是提供**身强 / 身弱**——即日主所在组的动态旺度与档位。
- 本引擎的**取格、成格、破格、救应、用神 / 相神 / 喜神 / 忌神、格局高低**，一律以本书为准，不沿用《四柱精髓》的格局口径。
- 两者冲突时（例如化气格与官煞格的先后、从格的成立条件），**以本书为准**；与旧口径的差异必须显式登记，不得静默覆盖。

**不在本期范围**：旺度算法的任何改动；流年 / 流月 / 流日 / 流时；起运重算；对已保存旧结果的回溯改写；命理断语（吉凶、六亲、事业）的生成。

## 取格总则（书的框架，供需求验收）

1. **月令为纲**：八字用神专求月令；先看月令本气与月令因会合而成的变格。
2. **有官先论官、有煞先论煞**：官煞有优先定格权，但以「与月令能组合成什么格」为前提；月令官煞不受损时最纯。
3. **官煞不成，再论化气；化气不成，再论他格**（书 第十章「先论官煞，再论合化」）。
4. **破格再取**：月令格破败、与官星构不成格局时，可另取他格（如弃官就食、弃印就财、去煞存财）。
5. **外格三前提**：月令无用神；干头无官煞；八字无财星能立足（书 第十二章）。
6. **有病方为贵**：格中忌神为病，有字去病为救应；破而复成仍是成格，只是层次不同。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 排盘后判出主格（Priority: P1）

使用者排完盘，系统按书的取格总则判出**一个主格**（49 格之一），并在多格并见时列出兼格；每条判定都给出书中的章节与条件编号。

**Why this priority**：格名是整条喜忌链的入口。没有格名，用神、相神、喜忌、高低都无从谈起。

**Independent Test**：取书中带明确格名的命例（如「乾 己卯 辛未 壬寅 辛亥」判正官配印格），只运行取格，断言格名与书一致。

**Acceptance Scenarios**：

1. **Given** 一张四柱完整的命盘，**When** 请求格局判定，**Then** 输出主格（49 格之一）与判定依据；多格并见时另列兼格。
2. **Given** 月令本气成格、但别位另有官星，**When** 判定，**Then** 按「月令为纲 + 有官先论官」的组合规则取舍，而不是简单取官。
3. **Given** 月令无用神、干头无官煞、无财星立足，**When** 判定，**Then** 按外格三前提进入外格判定。
4. **Given** 书中未收或条件不足的命盘，**When** 判定，**Then** 明确输出「未定」及缺口，不静默归入某一格。
5. **Given** 判定完成，**When** 回到排盘结果页，**Then** 原局格局喜忌摘要卡可见；点「查看详情」进入完整条件与书证。

### User Story 2 - 身强弱由现有旺度提供（Priority: P1）

使用者看到该盘的**身强 / 身弱**结论；该结论只能来自现有旺度引擎（日主所在组的动态旺度与档位），本引擎不另行计算旺衰。

**Why this priority**：书的喜忌规则以「身强 / 身弱」为分支；没有这一输入，用神方向无法落地。同时它是新旧两套体系唯一的接口，必须边界清楚。

**Independent Test**：同一命盘、同一旺度输入，重复判定得到同一身强弱；改变旺度输入（大运步）时，身强弱随该步变化，格名以原局为基准（允许按书变格）。

**Acceptance Scenarios**：

1. **Given** 一张命盘及其原局旺度结论，**When** 判定，**Then** 输出身强 / 身弱，并注明取自日主所在组的动态旺度与档位。
4. **Given** 主格为专旺 / 化气 / 从格，**When** 判定，**Then** 身强弱仍可输出供参考，但 MUST NOT 作为喜忌分支；喜忌按格本身决定。
2. **Given** 同盘的大运引擎2 某一步旺度，**When** 判定该步，**Then** 身强弱按该步旺度重取，格名仍按原局。
3. **Given** 旺度输入缺失（旧记录、未排盘），**When** 判定，**Then** 明确输出「身强弱未知」，不以猜测定性。

### User Story 3 - 用神、相神、喜神、忌神（Priority: P1）

使用者看到该格的**用神（格神）、相神、喜神、忌神**，以及它们与身强弱、病药的关系；每条都给出书证。

**Why this priority**：这是使用者要的「喜忌判断」主体；只有格名而没有喜忌，产品价值不完整。

**Independent Test**：取书中明确写出用神/喜忌的命例（如正官配印格「用印伏伤，最忌财星坏印」），断言用神、相神、忌神与书一致。

**Acceptance Scenarios**：

1. **Given** 主格已定、身强弱已知，**When** 请求喜忌，**Then** 输出用神、相神、喜神、忌神四类，并说明各自的角色。
2. **Given** 格中有病（如伤官克官、财坏印、官煞混杂），**When** 判定，**Then** 指出病在何字、有无救应；有救应时说明救应之字与效果。
3. **Given** 身强弱与格的默认方向不同（如身弱而格需财），**When** 判定，**Then** 按书的「病药 / 救应」规则给出取舍，并说明理由，而不是机械套用身强弱。
4. **Given** 喜忌判定完成，**When** 打开 `/geju` 详情页，**Then** 用神 / 相神 / 喜 / 忌四区与病药说明可见，且每条带书证。

### User Story 4 - 成格、破格、救应与格局高低（Priority: P2）

使用者看到该格是**成格、破格、破而复成**中的哪一种，以及格局高低（上 / 中 / 下）和对应的依据。

**Why this priority**：书的核心方法论是「去其忌而存其喜」「有病方为贵」；只有格名与喜忌而没有成破与高低，无法反映书的判断层次。

**Independent Test**：取书中明写「破格」「格成」「格高」「格低」的命例，逐例断言成破与高低。

**Acceptance Scenarios**：

1. **Given** 该格书列的破格条件之一成立且无救应（正官格取九条中的前七类），**When** 判定，**Then** 输出破格，并指出破格之字。
2. **Given** 破格条件成立但有救应之字，**When** 判定，**Then** 输出破而复成，并说明救应路径。
3. **Given** 该格书列的降格条件成立（正官格取九条中的后两类：重官不贵、财印互碍），**When** 判定，**Then** 输出降格而非破格。
4. **Given** 成格且相神有力、根气俱全，**When** 判定，**Then** 输出上 / 中 / 下三档之一及理由。

---

### User Story 5 - 外格覆盖（Priority: P2）

使用者能判出阳刃、禄劫、专旺、化气、从格、杂格六大外格及其小格；外格判定遵守书的三前提与各格成格条件。

**Why this priority**：书的一半篇幅在外格；只做内格会让大量命盘落入「未定」。

**Independent Test**：取书中外格命例（专旺、化气、从煞、从财、阳刃、禄劫各若干），断言格名与小格。

**Acceptance Scenarios**：

1. **Given** 月令建禄、比劫重重、有印、无财官食可用，**When** 判定，**Then** 进入专旺格并细分曲直/炎上/从革/润下/稼穑。
2. **Given** 日干参与五合且官煞格不成，**When** 判定，**Then** 按化气格条件判真化/假化及五种化神。
3. **Given** 满局官煞、日主虚浮无根、无印化食制，**When** 判定，**Then** 判弃命从煞（真从/假从）。
4. **Given** 月令无用、干头无官煞、无财星立足，**When** 判定，**Then** 按杂格条件判飞天禄马/六阴朝阳/合禄/井栏叉/刑合；书明确批判的「无理杂格」不得强行入格。

---

### User Story 6 - 大运喜忌（Priority: P2）

使用者逐步查看大运：格名以原局为基准（允许按书变格），身强弱按该步引擎2 旺度重取，行运喜忌按书各格的「行运喜忌」判定，并标出成格/破格的变化。

**Why this priority**：使用者已确认本期含大运；书每格都有「行运喜忌」，现有大运引擎2 可逐步提供旺度。

**Independent Test**：取书中带行运断语的命例，逐步断言喜忌方向与成破变化。

**Acceptance Scenarios**：

1. **Given** 原局格名已定，**When** 查看某步大运，**Then** 以原局格名为基准，身强弱按该步旺度重取，输出该步的行运喜忌；若触发变格，输出新格名与变化原因。
2. **Given** 该步大运触犯书中的行运禁忌（如专旺格行官煞运），**When** 查看，**Then** 标出破格/犯旺及依据。

### Edge Cases

- **月令无格**：月令本气与中气、余气都不成格，或月令被合化改宗——按书的「会合变格 / 破格再取 / 外格三前提」逐级下探，不得直接判「无格」。
- **多格并见**：一张盘同时满足两个格的成格条件（书中胡林翼例即「官喜财生 + 食神生财」双格并存）——输出主格 + 兼格，并说明取舍依据。
- **官煞混杂**：按书的「清格」规则（合煞、制煞、去官）判复成或破格，不得简单判「混杂即破」。
- **从 / 化 / 专旺的先后**：书明确「先论官煞，官煞不成，再论化气」；从格与专旺各有前提，不得相互顶替。
- **书内矛盾或未量化**：总论 / 分论 / 歌诀不一致、或只有歌诀没有可执行条件——**不自动裁决**，登记为开放项并在输出中标注「存疑 / 未定」，由人工裁定后补录；不得静默选一边。
- **缺时柱**：三柱判定，格局可靠度下降；凡依赖时柱的格（如时上偏财、时上一位贵等）必须标注降级。
- **旧记录**：没有完整入参、无法重算的旧记录——显示「无法判定」及原因，不伪造格名。
- **未收录的格**：书外或书中批判的格——不得强行归入 49 格中的近似项。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 本引擎的规则 MUST 以《格局真诠》为**唯一权威**；每条规则 MUST 可追溯到章节 + 条件编号（有命例者附命例页）。
- **FR-002**: 取格 MUST 按书的顺序：月令为纲（本气 / 中气 / 余气、透干、会合变格）→ 有官先论官 / 有煞先论煞 → 官煞不成再论化气 → 化气不成再论他格（含破格再取）→ 外格三前提。
- **FR-003**: 引擎 MUST 覆盖书自述的 **49 格**（内 27 + 外 22），并为每格给出格名、大类、小格、成格条件、破格条件、救应、用神/相神/喜忌、高低与书证。
- **FR-004**: 身强 / 身弱 MUST **只**取自现有旺度引擎的日主所在组动态旺度与档位；本引擎 MUST NOT 另行计算旺衰、MUST NOT 用旺度直接取用神。身强弱 MUST **只参与内格（正官、七煞、财、印、食、伤）与阳刃 / 禄劫**的喜忌；专旺、化气、从格、杂格的喜忌 MUST 由格本身决定，身强弱不参与。
- **FR-005**: 每格的成格条件 MUST 按书中的编号条件逐条判定；书给出替代路径的（如「或虽有煞也有字清格」）MUST 记录所走的分支。
- **FR-006**: 破格 MUST 区分「破格」与「降格」：按各格书列的破格 / 降格条件逐条判定；正官格的九条中前七类成立且无救应 → 破格，后两类 → 降格；其他格按其总论 / 分论的列举分别归类。不得混同。
- **FR-007**: 引擎 MUST 判「病」与「救应」：指出破格之字（病）、救应之字（药）及其作用路径；有救应时 MUST 输出「破而复成」，无救应时输出破格。
- **FR-008**: 引擎 MUST 输出用神（格神）、相神、喜神、忌神四类，并说明它们与格、身强弱、病药的关系；不得只给一个「用神」词。
- **FR-009**: 引擎 MUST 输出格局高低（上 / 中 / 下），依据限于书列的成破、救应、相神有力、根气、格清格浊等可观测条件。
- **FR-010**: 每条结论 MUST 附依据清单（格名依据、成格/破格依据、身强弱来源、用神/相神/喜忌依据、高低依据）；依据 MUST 引用书证，不得只写散文。
- **FR-011**: 凡书中无明文、**总论 / 分论 / 歌诀互相矛盾**、或只有歌诀无法执行的条件，引擎 MUST 输出「存疑 / 未定」并登记为开放项；MUST NOT 以任何默认顺序自动裁决、MUST NOT 以近似规则静默代替。
- **FR-012**: 缺时柱时，引擎 MUST 按三柱完成可判部分，并在结论中明示降级项与「格局可靠度下降」。
- **FR-013**: 本引擎 MUST NOT 改动现有旺度引擎（原局旺度、大运引擎2）的任何输出；两者并行，旺度输出逐位不变。
- **FR-014**: 引擎 MUST 处理多格并见：输出主格与兼格，并说明取舍；不得只保留一个而无说明。
- **FR-015**: 引擎 MUST 对未收录/不成立的命盘输出「未定」，并列出缺失的成格条件；不得兜底到某一格。
- **FR-016**: 大运喜忌 MUST 遵守：格名以原局为基准；身强弱按该步大运的旺度重取；行运喜忌按书各格的「行运喜忌」判定；成格/破格变化必须标注。**允许变格**（假从 ↔ 真从、假化 ↔ 真化、破格后另成他格），变格时必须输出新格名与变化原因。
- **FR-017**: 结果页 MUST 新增两张**摘要卡**（原局格局喜忌 / 当前大运格局喜忌），各带「查看详情」入口；详情页 MUST 承载完整成格条件、破格 / 救应、用神 / 相神 / 喜忌、高低与逐条书证。MUST NOT 改变现有两张旺度卡的内容与入口。
- **FR-018**: 对书中带明确格名的命例，引擎 MUST 支持逐例回测，输出一致/分歧清单，分歧逐条归因到规则或条件。
- **FR-019**: 大运逐步判定 MUST 输出该步的：身强弱（含该步旺度来源）、行运喜忌、成格/破格变化、及与上一步的差异说明；不得只给一句总评。
- **FR-020**: 术语 MUST 以书中原词为准（七煞、阳刃、印绶等）；界面 MUST 同时标注产品常用名（七杀、羊刃、正印 / 偏印），并维护一张可追溯的术语对照表；规则文本与依据 MUST 使用书中原词；API 的结构化十神字段（如 `ten_god`）MUST 用产品规范词，另带 `book_term` 承载书中原词。

### Key Entities *(include if feature involves data)*

- **格局定义（GeJuDefinition）**：格名、大类（内/外）、小格、书证位置、成格条件（编号）、破格条件、救应、用神/相神/喜忌、高低判据。
- **条件（Condition）**：书中的一条可执行条件；含条件文本、编号、所需命盘要素、判定结果、书证。
- **救应（Remedy）**：病（忌神）与药（救应之字）的对应关系、作用路径、成立前提。
- **命例（BookCase）**：四柱、书判格名、书判喜忌/成破/高低、书证页；作为回测与验收的锚点。
- **判定结果（Judgement）**：主格、兼格、成/破/复成、身强弱（含来源旺度）、用神/相神/喜神/忌神、病药、高低、依据清单、未定项。
- **身强弱输入（StrengthInput）**：日主所在组的动态旺度、档位、二值结论「强/弱」、来源（原局或某步大运）。
- **书证（Citation）**：章节、条件编号、命例页；所有规则与结论的追溯锚点。
- **存疑项（OpenIssue）**：书内矛盾/未表述的条件、冲突位置、各说原文、裁定状态；作为「未定」输出的依据与后续人工裁定的台账。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 对书中抽取的 **≥100 例**带明确格名的命例完成逐例回测；一致与分歧全部进入清单，每条分歧 MUST 归因到具体规则/条件；不设统一一致率门槛，但按大类报告一致率。
- **SC-002**: 49 格每格 MUST 有定义；书中提供命例的格 MUST 至少有 1 例进入回测；不得出现「未定义」的格名。
- **SC-003**: 100% 的判定结论 MUST 至少引用一条书证（章节 + 条件编号）；无书证的结论视为未完成。
- **SC-004**: 现有旺度引擎的全部输出（原局旺度、大运引擎2）MUST 逐位不变；以现有回归基线守门。
- **SC-005**: 每张被判定的命盘 MUST 给出完整的六项：格名、身强弱、用神/相神/喜/忌、成破/救应、高低、依据；缺任一项视为判定不完整。
- **SC-006**: 书中未定/矛盾项 MUST 全部显式标注并进入存疑清单；审计时不得发现「静默猜测」（即无书证却给出确定结论），也不得发现「按默认顺序选边」。
- **SC-007**: 单张命盘的格局与喜忌判定 MUST 在用户点击后即时呈现（无需等待批处理）。
- **SC-008**: 多格并见的命盘 MUST 同时给出主格与兼格，并说明取舍；只给一格且无说明的视为不完整。
- **SC-009**: 大运的每一可用步 MUST 给出该步身强弱、行运喜忌与成/破变化；格名 MUST 以原局为基准，变格时 MUST 给出新格名与原因；缺任一项视为该步判定不完整。
- **SC-010**: 结果页 MUST 显示原局与当前大运的格局喜忌摘要；详情页 MUST 可查看完整成格条件、破格 / 救应、用神 / 相神 / 喜忌、高低与书证。
- **SC-011**: 术语对照表 MUST 覆盖书中出现且与产品不同的全部十神 / 格名词；界面上的每个书术语 MUST 能对应到一个产品常用名。

## Assumptions

- 本书（2018 年版）是本期的唯一权威；与《四柱精髓》冲突时以本书为准，并登记差异。
- **身强弱分界**已确认为现有旺度的中和点（10 度）：日主组动态旺度 ≥10 为身强，<10 为身弱。身强弱只用于内格与阳刃 / 禄劫；专旺 / 化气 / 从格 / 杂格由格定喜忌。
- 本期含**原局 + 大运**；流年 / 流月 / 流日 / 流时不纳入。
- 49 格全量定义；其中书明确批判的「无理杂格」仍给出定义与「存疑」标注，但不强行入格。
- 现有旺度引擎不变；本引擎只消费其日主组动态旺度与档位，不消费其旧的格局/用神结论（那些已从产品中移除）。
- 书中的命例是主要验收锚点；书中只有过程分析、没有明确格名的例子不作格名验收锚点。
- 书内矛盾不自动选边：遇总论 / 分论 / 歌诀不一致，先输出「存疑 / 未定」并登记，待人工裁定后再补录规则。
- 术语对照表随规则表一并维护；规则文本用书中原词，界面标产品常用名。
- 旧记录不回溯改写；无法重算的记录显示「无法判定」。

## Clarifications

### Session 2026-10-28

- Q: 覆盖范围？ → A: **49 格全量**（内 27 + 外 22）一次交付。
- Q: 身强弱分界？ → A: **中和 10 度**：日主组动态旺度 ≥10 为身强，<10 为身弱。
- Q: 大运喜忌是否纳入？ → A: **纳入**：原局 + 大运；格名以原局为基准（允许按书变格），身强弱按该步大运旺度重取；流年 / 流月 / 流日 / 流时排除。
- Q: 身强弱适用于哪些格？ → A: **只用于内格与阳刃 / 禄劫**；专旺、化气、从格、杂格的喜忌由格本身决定，身强弱不参与。
- Q: 大运是否允许改变格名？ → A: **允许变格**：假从 ↔ 真从、假化 ↔ 真化、破格后另成他格；输出新格名与变化原因。

- Q: 术语以哪一套为准？ → A: 规则与格名用**书中原词**；界面同时标注产品常用名（七煞（七杀）、阳刃（羊刃）、印绶（正印 / 偏印）），并维护术语对照表。
