# Data Model: 大运引擎2

**Feature**: `014-dayun-engine2` | **Date**: 2026-10-13 | **Spec**: [spec.md](spec.md) | **Research**: [research.md](research.md)

本期**不新增任何持久化**（FR-008）——以下全部是**按需实时产出**的响应形状，不落库、不进 `chart_result`。

---

## §1 输入：五柱序列

引擎2 的输入**只有**两样：原局四柱（既有排盘产出）与该步大运的干支。**不读现引擎的任何中间量**（FR-004）。

「五柱」= 四柱 ＋ 大运柱，按下列**线性序列**排布（第 3 步的连片与相邻判定都在这条序列上做）：

```text
年干 · 年支 · 月干 · 月支 · 日干 · 日支 · 时干 · 时支 · 大运干 · 大运支
```

| 字段 | 来源 | 说明 |
|---|---|---|
| `pillars` | 既有排盘 | 年/月/日/时四柱的干支（缺时柱时为三柱） |
| `dayun.ganzhi` | 既有大运步 | 该步的干支对，如 `"辛亥"` |
| `dayun.start_year` / `start_age_xu` | 既有大运步 | **原样带出**，不重算（FR-010） |

**约束**：大运干、大运支 MUST 出现在序列末两位（澄清④）；运干与运支**不拆开**（十年一体，FR-013）。

## §3 逐步依据（`phases`）

**八条**（换字成功时**九条**），**次序即 FR-001 的次序**，每条 `{ key, title, shared?, traces[], subtotal? }`：

| # | `key` | 该步 MUST 给出的中间量 | `shared` |
|---|---|---|---|
| 1 | `relations` | 十八层判定的**全部条**（成立与让位；含不含大运的那些条——原局内部的关系同样是这一步的判定结果），每条成立关系再逐条给它对**藏干度数**的影响（每条规则一行 ＋ 每个受影响藏干一行净变化） | **`true`**——两套共用同一份判定（澄清①），照常呈现、不另算 |
| 2 | `month_coef` | 每个五行的月令系数与其状态名 | |
| 3 | `tonggen5` | 每个五行的五柱通根明细：各柱的藏干贡献、相邻递减、连片合并 | |
| 4 | `static` | 每个五行的「通根 × 月令系数」乘积，以及运支状态增减、运干同类相助两项增量 —— 三项可逐位对上（SC-002） | |
| 5 | `stem_he` | 天干五合：候选对（原局相邻 ＋ **岁运之干与原局任何一柱**）、争合仲裁、五条件的判定、**合化换字**、**合而不化的合绊成数**（R30；与现引擎共用 `stem_he.judge_stem_he`） | |
| 6 | `static_he` | **换字后重算静态**——按新字重跑月令系数/五柱通根/静态，并施加合绊减量。**仅真换过字时出现**（故段数 8 或 9） | |
| 7 | `dayun_pair` | 运干 ↔ **运支本气**的同柱生克（**O5 定案**：受方取**本气实例**＝本气藏干 × 月令系数，书 上 1008）：成数、两边各自的结果；运干每次分别计算取同一值（裁定②）；**生克权按五行整体静态判、成数按本气算**（R32，2026-10-23） | |
| 8 | `dayun_to_pillars` | 运干 ↔ 四柱四干**各一次**：每次的成数、四柱各自被作用后的值；运干在该组的取值**每次相同**（裁定②） | |
| 9 | `natal_internal` | 剩余分数（＝上一步之后四柱各节点的值，澄清③）作为起点，**只喂四柱、按原局方式**（现引擎 `stem_layer`：天干组 ＋ 同柱本气、受/生/克三批）结算，及由此得出的动态旺度（R31） | |

**每条的 `traces` 项**沿用既有依据行的形状（`{target, expression, value}`），使：
(a) 页面上逐条可读；(b) 与既有依据行的渲染组件同构，前端无需造第二套渲染。

## §4 一次请求的响应

```jsonc
{
  "engine": "dayun-engine2",
  "engine_version": 1,
  "input_scope": "four_pillars" | "three_pillars",
  "degradations": [ … ],            // 缺时柱/未起运等说明，与现引擎同源
  "dayun_steps": [ …§2 的条目，按步序… ]
}
```

**大运步的枚举**：按该盘既有的全部大运步，**每步独立计算**（一步的数不带入下一步）。

## §5 不变量（测试的抓手）

| # | 不变量 | 对应 |
|---|---|---|
| I-1 | 任一步的 `elements` **恒有 5 项**，五行齐全 | SC-004 |
| I-2 | 任一步的 `phases` **恒有 8 条**（`static_he` 只在真换过字时出现，此时 9 条），`key` 与上表一致 | SC-002 |
| I-3 | `day_master.dynamic` 恒等于 `instances` 中 `kind=="stem_group"` 且含日主那一组的 `dynamic` | FR-002.2 |
| I-4 | `elements[wx].static` 对**透干**五行恒等于该五行各 `stem_group` 实例 `static` 之和 | §2.1 |
| I-5 | 第 4 步的「通根 × 系数 ＋ 两项增量」三项相加恒等于 `elements[wx].static` | SC-002 的验收点 |
| I-6 | **现引擎的数在改动前后逐位相同** | SC-003 |
| I-7 | 现引擎模块的 import 图里**不出现**引擎2 模块 | FR-004（结构守门，见 research D9） |
