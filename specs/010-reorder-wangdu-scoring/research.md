# Phase 0 Research: 五行打分整体顺序重构——定性(1-5) → 定量(6-11)

**Feature**: `010-reorder-wangdu-scoring` | **Date**: 2026-08-27 | **Branch**: `010-reorder-wangdu-scoring`
**依据**: [spec.md](spec.md)（含 Clarifications Q1-Q3）+ [009 research](../009-wangdu-static-dynamic/research.md) + 现状代码 `backend/src/services/bazi/wangdu.py`、`frontend/src/types.ts`、`backend/tests/contract/test_charts_api.py`

## R1: 11 步流水线到引擎操作的映射

- **Decision**: `compute_wangdu` 内部重组为 定性(第1-5步) → 定量(第6-11步)：
  - **定性（只判定性质与归属，不做刑冲破害数值）**：
    1. **月令能否合化**：判定月令支参与的三合/三会/六合/半三合能否化成功（复用现有合化条件 `_sanhe_hui_ok`/`_liuhe_verdict`/`_banhe_verdict`）。化成功 → `month_effective_wx`=化神；合绊/未合 → =原始月令本气。争合按既有规则取一。**藏干重组不在本步落地**（合并到第3步一次完成）。
    2. **月令旺相休囚死**：基于 `month_effective_wx` 判各五行状态（`element_state` + `_MONTH_STATE_OVERRIDE` + 燥戌），输出状态表供第9步系数。
    3. **地支关系判定**：`judge_relations(only_branch=True)` 全量判定（书 §9 论处先后，让位维持 009，Q1=B）。**合化成功的支做藏干重组**（变纯化神、原藏干作废）——性质改变在本步落地；刑冲破害的成立/让位在本步定性，**数值不入本步**。
    4. **地支根气保留**：在第3步判定结果上，判定各支各五行根气"保留/去除"（合化消费、刑冲破害定性去根、真正合绊 → 不留），输出 `root_preserved` 供第8步通根与 geju 消费。
    5. **天干能否合化**：紧贴三对判天干五合能否化成功（用第2步状态基准），化成功 → 两干 `gan_hua` 归属改变（性质改变）。
  - **定量（落数值）**：
    6. **五行基础分数**：天干（`gan_hua` 归属，原始1度）+ 藏干（定性后重组藏干）求和。
    7. **地支刑冲破害数值**：对第3步判定的 刑/冲/害/破 + 合绊减力 应用藏干数值修正（复用现有 effect 函数：增减/减半/归零）。合绊不改变性质、其减力并入本步（R8 裁定）。
    8. **计算通根**：`_wx_degrees` 通根递减（透干/不透干、月令特权、柱距折扣），藏干侧 + 天干侧，消费第4步根气（被去除的根不参与）。
    9. **旺相休囚系数**：× `COEF[第2步状态]`，基准含月令化神单基准（Q2=A，**不再双状态平均**）。
    10. **天干生克**：紧贴三对（Q3=A），**先合-冲、再生克**；生克优先级 同性克>异性生>异性克>同性生（Q1=B）；含天干冲数值（按同性克倍率）与同柱生克（R3）。
    11. **总分数**：合并修正后天干 + 修正后藏干，×系数（单基准），对照阈值表定旺衰等级。
- **Rationale**: 用户 11 步顺序字面即流水线；定性阶段只改"归属/性质"（合化化神、根气去留），定量阶段才改"数值"（刑冲破害/合绊减力、通根、系数、天干倍率）——与"1-5 无性质改变按原始五行、有改变按新数值"的总原则一致。
- **Alternatives**: 仅在展示层重排 steps、计算不动（被否——用户要的是计算顺序本身）；把刑冲破害数值留在定性阶段（被否——用户明确 6 先算分、7 才刑冲破害数值）。

## R2: 月令合化前置 + 单一化神基准（澄清 Q2=A）

- **Decision**: 新增 `month_effective_wx` 判定（第1步），取代 009 的"静态用原始月令 + final 双状态平均"：
  - 第1步：月令支参与合局化成功 → `month_effective_wx` = 化神；否则 = 原始月令本气。
  - 第2步/第9步/第11步：状态基准一律用 `month_effective_wx`（`_xu_state(wx, month_zhi, dry)` 改为对 `month_effective_wx` 判状态）。**取消双状态平均**（009 中 `s2 = raw1×COEF[element_state(wx, month_hua)]` 分支删除）。
  - 月令合化成功的藏干重组仍按现有合化数值（六合11/半三合12/三合18/三会24 度），只是系数基准变为单一化神。
- **Rationale**: 用户 Q2=A 明确"化成功按所化五行判断"，即单一化神基准。月令合化类命例（如子丑合化水、亥卯未三合木）的旺相休囚死与系数将按化神算——这是与 009 最大的行为差异。
- **Alternatives**: 保留双状态平均（被否——用户选 A）；分合局类型不同基准（被否——用户选 A 单一）。

## R3: 天干层重构——先合-冲再生克、优先级、天干冲数值（澄清 Q1=B / Q3=A）

- **Decision**: 第10步天干层（替代 009 的 dynamic_a + dynamic_b）：
  - **范围**：紧贴三对（年-月/月-日/日-时），天干合隔位不论、生克紧贴才进度数、岁运介入可论（Q3=A）。
  - **次序**：每对**先判天干五合（含争合）与天干相冲，再判普通生克**。
    - 合化成功 → 两干 `gan_hua` 归属改化神；合绊 → 主克×0.8/受×0.5、贪合忘生克（沿用 009）。
    - 天干冲（甲庚/乙辛/丙壬/丁癸，皆同性）→ 按**同性相克倍率**（主×0.7/受×0.5）进度数（009 天干冲不进度数，010 新增）。被合化消费的干不再论冲（先合后冲，让位）。
  - **生克优先级**：同性相克 > 异性相生 > 异性相克 > 同性相生（Q1=B，作判定/让位次序——同干涉多关系时高优先级先处理，数值沿用现行 `_TZSG_FACTOR` 倍率、基本不变）。
  - **同柱生克**（009 dynamic_b，干↔本柱全部藏干）并入本步，traces 以"天干间"与"同柱"子项区分；生克权基准用第9步系数后分数。
- **Rationale**: Q3=A 范围紧贴三对；Q1=B 优先级作次序；天干冲入数值是"先计算合-冲"的字面要求。同柱生克属"天干参与的生克作用体系"，并入第10步最贴合 11 步结构（用户 Q2=A 只要 11 键，无独立同柱键）。
- **Alternatives**: 同柱生克留在某藏干步（被否——它改天干也改藏干，且生克权判定与天干层一体）；天干冲仍不进度数（被否——用户第10步明列"合-冲"）。

## R4: 第 4 步根气保留判定与消费

- **Decision**: 新增第4步根气判定：在各支经第3步关系判定后（合化消费/刑冲破害定性去根/真正合绊），输出 `root_preserved: {支: {五行: bool}}`。
  - **判定口径**：该支该五行藏干是否仍有效（未被作废/归零）；"真正合绊"沿用 `_branch_bound_set`（仅 六合/三合/三会 合绊绊根；半三合不化不绊根，2026-08-22 口径）。
  - **消费**：① 第8步通根——被去根之支不贡献根；② geju——`_dm_effective_root` / `_dm_stem_help` 的"根气"输入改用本步结果（spec FR-014），从格判定口径（藏同类≥1.0 含余气）不变。
- **Rationale**: 用户第4步明列"地支改变后是否保留根气"，是定性结论，向下游（通根/从格）提供统一根气视图；009 中根气散落在 `banished`/`_branch_bound_set`/刑冲破害函数各处，010 收敛为一步。
- **Alternatives**: 根气判定继续内嵌在通根与从格各自计算（被否——用户要第4步显式定性，展示需要）。

## R6: TDD 测试策略（宪法 II）

- **Decision**: 先写失败测试再实现：
  - **后端 `test_wangdu.py` 新锚点**：
    1. **月令合化单基准**：子丑合化水（丑月）命例，断言第2步状态/系数基准=水（与 009 双状态平均数值差异记录）；月令合绊命例断言基准=原始。
    2. **定性/定量分离**：合化成功命例，`branch_rel` 步即完成藏干重组、`branch_effects` 步无合化数值；刑冲破害命例，`branch_rel` 定性、`branch_effects` 落数值。
    3. **根气保留联动**：刑冲破害去根命例，第4步根气"不留"，通根与从格均不使用该根。
    4. **天干层先合-冲再生克**：含天干冲（甲庚等）命例，第10步冲按同性克倍率进度数 trace；合绊贪合忘生克无生克倍率 trace。
    5. **生克优先级**：同干涉多关系的构造盘，断言按 同性克>异性生>异性克>同性生 次序处理。
    6. **11+3 键序列**：`steps` 键断言。
    7. **009/008 锚点重跑对照**：逐例断言新结果；月令合化类与含天干冲类记录新旧差异，其余不回归。
  - **契约 `test_charts_api.py`**：steps 键断言更新为 14 键新序列。
  - **前端 `types.ts`**：`WangduStep.key` 联合类型更新为 14 键。
- **Rationale**: 顺序重构的正确性验证必须落在"新旧顺序差异"的可观测断言上（月令合化单基准是最强判据）；009/008 已有大量锚点，重跑对照是验收基准（SC-001）。
- **Alternatives**: 仅重跑旧锚点不看差异（被否——单基准必然改变月令合化命例，必须逐例说明）。

## R7: 性能与范围确认

- **Decision**: 11 步为纯函数顺序重排，无 IO、无循环爆炸（≤10 大运预计算沿用）；排盘响应体积增量来自 11 键 traces（估计 <30KB）。前端仅 `types.ts` 类型更新，`relations.ts`/`StrengthDetail.vue` 不动（spec Assumptions：命盘图维持 009）。
- **Rationale**: 既有 009 已是毫秒级纯函数，010 只重排顺序、数值函数复用，无性能风险。
- **Alternatives**: 无。

## R8: 遗留裁定（Deferred → 定案）

- **步骤键命名**：定案见 R5/data-model（14 键）。
- **合绊减力归属**：合绊（六合/三合/半三合合绊）不改变五行性质，其藏干减力并入**第7步"地支刑冲破害数值"**（traces 内以"刑/冲/害/破/合绊"子项区分）；第6步基础分=定性后藏干（合化重组后、未减力）。
- **天干冲让位细则**：按"先合-冲"——天干先判合化/合绊（合化消费的干不再论冲）；合绊与冲同支时按生克优先级（同性克最高）让位。数值最小落地，不引入额外状态。
- **月令参与的非合化地支关系**（如月令支与别支相冲/刑/害）：在第3步统一判定（月令合化已在第1步定性，其藏干重组在第3步一并完成）。
- **从格/取用神下游**：规则不变，仅"根气保留"输入改用第4步结果（spec FR-014）。
