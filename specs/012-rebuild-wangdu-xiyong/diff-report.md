## 预期口径差异（非缺陷）

- **O-5**：严格让位：同一支被多对关系命中时低优先级失效、影响不叠加（书里部分算例按叠加分析）
- **C26-5**：C24 字面根气作废，从格改用「不能独立」公式
- **C26-7**：2.4 归比弱侧
- **C26-1(2026-09-11)**：《初级答疑》书源撤销：同类多作用改**相加**（原「抓大放小」取最大）、巳中庚金不再随热月去除、辰戌冲不成功按书 下 1731-1758 逐藏干变化、四库党众计入天干并须「连成一片」、调候与旬空不再量化、贴身只取日支/月干/时干
- **F3(2026-09-11)**：生克结算改**全盘逐实例「先受后施」**（先受入的生克、再施出的生、最后施出的克；**同柱对先算完再算天干对；生克权按五行全盘动态合计判、成数按自身度数算**），受生范围的「有气」改按书 上 353 的月令状态；删除无书证的「主生者太旺 → 受生者反减半」分支
- **F3/C26-17·C26-21(2026-09-16)**：生克结算改**相内依赖序**（凡作用于我的对，其主方都要先轮到——《入门》1486-1488 法则③「克者有克则不克」）；一对拆两段：主方当轮**定档并自负减力**、受方当轮**一次施加**（保住「先生后克」与同批相加）；新增**施批闸门**——受后失去生克权、或由有度被打散到 0 者，其施生/施克整批不作（「生者有克则不生」）
- **C26-22(2026-09-16)**：天干五合条件④「弱方不能独立」改按**动态旺度**（书 上 1588）：先把这个五合**按合绊试算到底**、取**弱方那个字所在组**的终值，不足 2.4 度才算不能独立，此时才换字**重头算一遍**；原口径喂的是换字前、不含合绊减力的静态旺度
- **C26-23(2026-09-16)**：动态旺度重设计：**合 → 生 → 克 三段**，每批算完更新、**批内取同一快照**；**同一单位在同一类里只取影响最大的一路**（《入门》1498「抓大放小」，取代 C26-1 的「同类多作用相加」）、**不同单位各算各的**；批内**先受后施**；两相（同柱先、天干后）取消。C26-1 当初把 书 上 2325（第三节「地支特殊生克」的未土克酉金，属关系层）挪用到结算层是引错了层
