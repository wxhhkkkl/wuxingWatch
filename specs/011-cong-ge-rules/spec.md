# Feature Specification: 从格判定规则重写（专家新标准，阴阳干分口径）

**Feature Branch**: `011-cong-ge-rules`
**Created**: 2026-09-03
**Status**: Draft
**Input**: 专家给定从格新标准（从强/从印/从弱，阳干阴干不同口径），并入 010 引擎后重写从格判定。

## Summary

《四柱精髓》旺度引擎的从格判定（[wangdu.py](backend/src/services/bazi/wangdu.py) `_judge_geju`，裁定 C21）自 2026-08-22 校准后，现按**专家最新给出的从格标准**重写，覆盖 **从强 / 从印 / 从弱** 三类，并区分 **阳干/阴干** 的日主根气口径。化格判定（日主参与的天干五合合化成功，C5）优先级与口径**不变**。

新标准整体比现行更严、更"结构化"：日主根气从"计算后无根"改为"**阳干字面见根即不从**"；从印/从强门槛由数值独立改为"数值 + 透干且有根"组合判定；从弱细分三种所从之神（食伤/财/官杀），从神必须"极强（≥26）且无交战"。

## Clarifications

### Session 2026-09-03（对话中用户拍板）

- **C24-1 从神选择**：{食伤, 财, 官杀} 中取 `final ≥ 26` 且禁令清单干净者，**取最强者**为从神；无任何从神满足 → 不从弱（落正格）。
- **C24-2 "有根/有根气"判据**：**只对合化成功的支**按合化后算（原藏干作废，不算根）；其余一律按**字面藏干**——刑冲破害/合绊（不化）都**不除根**，藏干表含该五行即算有根（含余气）。
- **C24-3 "比劫"透干判定排除日主柱**：仅看年/月/时柱天干是否带 W 五行；日主自身不算"比劫透干"。
- **C24-4 "根被削弱/消耗"的量化**：该根所在支被相应关系作用后，该支藏 W **残余 < 2.4** 才算"被削弱"；日主有多个根支时，**任一未削到 <2.4 的根支即挡从**。从印用 冲/刑/合；从弱阴干用 刑冲破害（文字差异照字面分别处理）。
- **C24-5 显示标签**：从杀 / 从财 / 从印 **细分显示**（沿用枚举 `cong_sha / cong_cai / cong_yin`）；从食伤归 `cong_ruo`。内部记录所从之神（从神五行）供取用神。
- **C24-6 嵌套优先**：从食伤的"比劫不得有根"比从弱前置1（阴干允许削弱根）更严，从食伤分支内按字面"比劫不得有任何根"。
- **C24-7 化格不变**：仍为最高优先级（日主参与的天干五合合化成功 → 化格）。
- **C24-8 新规则为最新口径**：本次允许翻转既往 08-18 / 08-22 老师认可但与新标准冲突的锚点（如 [204][259][176] 等）；旧师评作为历史记录保留在对照文档。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 引擎按新标准判定从格（P1）

用户输入任意八字命例，旺度引擎在化格之后、正格之前，按专家新标准判定是否从格以及从的类型（从强 / 从印 / 从弱，从弱细分从食伤→从弱、从财、从杀），并把判定依据（根气、透干、从神强度与禁令）写进 `ge_ju.basis` 供步骤展示。

**Why this priority**: 从格判定直接决定命主的旺衰结论、取用神与喜忌方向，是 008-010 输出的核心。新标准要求更严格的"真从"判断，防止把有根/有印的日主误判为从格。

**Independent Test**: 对代表性命例调用引擎，断言 `ge_ju.type` 与 `basis` 依据。可脱离其它功能独立验证。

**Acceptance Scenarios**:

1. **Given** 日主旺度 ≥26 的命例，**When** 官杀/财/食伤三方各自 <2.4 且皆不 [透干且有根]，**Then** 判 `cong_qiang`。
2. **Given** 日主旺度 ≥26 的命例，**When** 官杀/财/食伤三方中任一方 ≥2.4 或 [透干且有根]，**Then** 不从强，落正格（太旺宜泄）或继续下判。
3. **Given** 印（生日主五行）旺度 ≥26、比劫/财/食伤三方各自 <2.4 且皆不 [透干且有根] 的命例，**When** 阳干日主地支字面无日主之根，**Then** 判 `cong_yin`。
4. **Given** 同上但日主为阴干且地支带根，**When** 该根支经 冲/刑/合 作用后残余 <2.4，**Then** 判 `cong_yin`；若根未被削弱至 <2.4，**Then** 不从印。
5. **Given** 日主旺度 <2.4 的命例，**When** 阳干日主四支字面出现日主根气之字（哪怕已刑冲破害），**Then** 不从弱。
6. **Given** 日主旺度 <2.4、无根（或阴干根已削弱）且印不透干或印无根的命例，**When** {食伤, 财, 官杀} 中某方 ≥26 且其禁令清单干净，**Then** 判对应从弱（从食伤→`cong_ruo`、从财→`cong_cai`、从官杀→`cong_sha`），标签取最强者。

### User Story 2 - 全量命例对拍，翻转可追溯（P2）

对《四柱精髓》全书 361 命例做全量对拍，输出"旧引擎 / 新引擎 / 书结论 / 师评"的差异清单，尤其标出**从格↔正格翻转**项，写入对照文档与锚点差异记录，保证每次规则收紧的副作用可见、可裁决。

**Why this priority**: 新规则会翻转一批既有老师认可的锚点（预期两位数），必须文档化、逐个裁决，避免静默改判。

**Independent Test**: 运行全量对拍脚本，核对生成文档中翻转清单与引擎实际输出一致。

**Acceptance Scenarios**:

1. **Given** 全量 361 命例对拍结果，**When** 引擎按新规则运行，**Then** 翻转项（从格与旧结论相反）全部列在差异文档中。
2. **Given** 每条翻转项，**When** 人工核对新规则判定依据，**Then** 每条均可从 `basis` 解释。

---

### User Story 3 - 后端取用神与前端展示同步（P3）

后端取用神逻辑与前端命盘/格局展示随新从格类型同步：从神细分（印/财/杀）继续驱动喜忌方向；前端类型与文案与后端一致。

**Why this priority**: 从格类型改变会传导到用神/喜忌结论与界面标签，需保持一致。

**Independent Test**: 端到端调用同一命例，断言后端结论与前端渲染的格局标签一致。

**Acceptance Scenarios**:

1. **Given** 一条判为 `cong_cai` 的命例，**When** 前端展示，**Then** 格局标签为"从财格"，取用财与喜忌与后端 `xiyong` 一致。

---

### Edge Cases

- 化格命中但又不满足任何从格条件时，仍为化格（优先级最高，不落入从格）。
- 日主 <2.4、无根、无印帮扶，但 {食伤,财,官杀} **无一 ≥26** → 不从弱，落正格（弱极身弱）。
- 日主弱且有根（阴干削弱未至 <2.4 / 阳干字面见根）但无印透干 → 不从弱，落正格。
- 从印与从弱同时在日主 <2.4 时可能竞争（印 ≥26 vs 从神 ∈{食伤,财,官杀} ≥26）：从印需比劫/财/食伤 <2.4，故印 ≥26 时从食伤必不成立（食伤 <2.4 门槛）；从财/从杀仍可能（其禁令不含印，仅从印需比劫<2.4 全局已满足）。以 C24-1 取最强者裁决。
- 地支支被"合绊（不化）"：新口径下**不算除根**（C24-2），字面根仍在 → 该类旧锚点（如 [133]）将从弱翻正格，需入翻转清单。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**：引擎判定顺序须为 化格 → 从强 → 从印 → 从弱 → 正格；化格条件不变（C24-7）。
- **FR-002**：从强须满足 日主 W≥26 且 官杀、财、食伤三方 final 各自 <2.4，且三方皆不 [透干且有根]，不分阴阳。
- **FR-003**：从印须满足 印≥26 且 比劫、财、食伤三方 final 各自 <2.4，且三方皆不 [透干且有根]；日主根按阴阳分口径（阳干字面无根；阴干可带根但须冲/刑/合削弱至残余 <2.4）。
- **FR-004**：从弱前置——日主 final <2.4；阳干字面四支不得见日主根气之字（刑冲破害残留也算）；阴干可有根但须刑冲破害削弱至残余 <2.4。
- **FR-005**：从弱前置——若天干有正/偏印（透干），印不得有**任何一点根气**（字面），有即不从弱。
- **FR-006**：从弱须从神 ∈ {食伤,财,官杀} final ≥26 且其禁令清单干净，取最强者为从神（C24-1）；禁令清单：
  - 从食伤（→`cong_ruo`）：印、官杀 各<2.4 且不[透干且有根]；比劫可有但字面不得有根（C24-6）。
  - 从财（→`cong_cai`）：比劫、印 各<2.4 且不[透干且有根]。
  - 从官杀（→`cong_sha`）：印、食伤、比劫 各<2.4 且不[透干且有根]。
- **FR-007**：无任何从神满足 FR-006 → 不从弱，落正格。
- **FR-008**：根气判据统一按 C24-2：合化成功之支按合化后（原藏干作废），其余字面藏干存在（含余气）即算有根；"比劫"透干排除日主柱（C24-3）。
- **FR-009**：从格类型须细分显示（C24-5）：`cong_qiang / cong_yin / cong_sha / cong_cai / cong_ruo`，内部记录所从之神供取用神。
- **FR-010**：判定依据（根气、透干、从神强度与禁令判定、削弱动作）须写入 `ge_ju.basis`，供步骤展示与对拍解释。
- **FR-011**：全量 361 命例对拍与锚点差异记录须同步更新，翻转项可追溯（C24-8）。

### Key Entities

- **日主（day master）**：命例之主天干及其五行 W；判定时需阴阳属性。
- **日主根气**：四地支中与 W 同五行的字面藏干（含余气）；受 C24-2/3/4 口径约束。
- **从神**：从格所顺从的五行方向——从强=顺日主、从印=顺印、从弱=顺 {食伤, 财, 官杀} 之一。
- **禁令清单元素**：判定从弱/从印是否"有交战"的敌对五行，需同时查 度数阈值（<2.4）与 [透干且有根]。
- **格局类型**：`hua / cong_qiang / cong_yin / cong_sha / cong_cai / cong_ruo / zheng`，各带 `basis` 依据。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**：对已定翻转锚点（如 [204][259][176][207][74][133] 等）单测断言与引擎输出一致，红→绿闭环。
- **SC-002**：全量 pytest（后端 + 前端）通过，无方向性错误（该从判不从、该不从判从）遗留。
- **SC-003**：全量 361 命例对拍产出翻转清单，差异文档与锚点差异记录更新，每条翻转有 `basis` 可解释。
- **SC-004**：前端命盘/步骤展示的从格标签与后端 `xiyong` 结论一致（从神细分传导正确）。

## Assumptions

- 本功能为纯领域引擎规则修订（008-010 同一模块），沿用 010 的 14 键步骤管线与 `final_scores` 口径；不改动步骤顺序。
- "旺度极强 ≥26"沿用引擎"太旺以上"档位（LEVEL_BANDS）；"<2.4"沿用"太弱以下"档位。
- 化格、月令合化、地支刑冲合害的度数计算均**不受本功能影响**，仅复用其结果判定根气（C24-2 依赖"合化成功作废"的既有状态）。
- 新规则为最新口径，既往师评（08-18/08-22）与书结论若冲突以新规则 + 用户拍板为准，历史差异保留在文档。
- 从弱细分沿用现有标签命名；若未来专家给"从食伤"专属标签再做展示层扩展，本功能只保证内部从神字段可用。
- 范围仅含"从格判定"本身及其下游取用神/展示同步；调候、神煞、空亡等不受影响。
