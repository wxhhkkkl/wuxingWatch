# Feature Specification: 岁运判定（大运与流年加入后的推导）

**Feature Branch**: `013-dayun-liunian-judgment`
**Created**: 2026-09-21
**Status**: Draft
**Input**: User description: "给当前引擎加入大运和流年的判定，要保留当前计算结果，新开一个页面单独查看加入大运和流年加入后的推导结果。**（2026-09-21 修订，推翻原「流年不参与强度计算」）** 分阶段、一步一步计算：先算大运，再在其上算一轮流年；分**三个页面**——原局页、加入大运后的页、加入流年后的页；**流年也参与关系和度数**。"

## 背景与边界

012 期已建成以「原局四柱」为输入的旺度与喜忌引擎（换字后重判、十八级让位、逐段依据），
并把「逐步大运的用神变化」列为 US4 完成。**但岁运维度只到「数据与展示」为止**：

- 大运的干支序列、起止年份与逐年流年已由排盘上游算出（004 期的联动展示即消费它）；
- 命盘图能看出「某步大运参与的关系」，逐步大运也用神可查；
- **而判定本身仍以原局月令为准**——岁运介入时应改用的「综合（折中）状态」判据尚未生效，
  岁运支也未能把原局相隔之支「桥接」为相邻。

本期的目标即把岁运真正接入**判定**，**分三个阶段、一步一步**算——原局 → 加入大运 → 加入流年——每个阶段**各成一页**；同时严格保证**原局结论一字不变**。

### 术语（本规格内的固定用法）

| 术语 | 定义 |
|---|---|
| **大运** / **流年** | 两个**独立**的阶段对象。凡需按阶段区分处，一律直书「大运」「流年」，**不写「岁运」** |
| **岁运** | **大运与流年的合称**，仅用于「两者同规则、不必区分」的场合（如相邻性、参与刑冲合害） |
| **阶段** | 原局（1）／加入大运（2）／加入流年（3）；后一阶段在**前一阶段的结果之上**增量，不独立重算 |
| **来源阶段** | 每项结论的归属标记：属原局 / 属大运 / 属流年——**只标一个**（FR-024） |
| **综合（折中）状态** | (月令参数 + 大运参数) / 2；参数 旺1/余气2/相3/休4/囚5/死6，≤3 当令。**流年不参与**（FR-003 / FR-017a） |
| **桥接** | 岁运介入使原局相隔之支**变为可作用**（书 上 1541 / 下 1684） |
| **门控** | 命 → 运 → 岁：流年之支被该步大运合/冲/合绊住则**作用不到原局**（书 下 4430/4468） |

> 书证行号基准：`d:/tmp/newdocs/norm/` 下的归一化文本（「上/下 NNNN」，自 012 期沿用）。

### 与既往各期的关系

| 期 | 内容 | 与本期的关系 |
|---|---|---|
| 004 | 大运/流年的**展示与联动**（横条、四柱细盘、神煞） | 本期不动展示层，只补判定 |
| 012 | 原局旺度与喜忌引擎、逐步大运用神（US4） | 本期在其上叠加岁运判定；原局路径必须保持 |

### 本期不做

- 流月、流日、流时的判定（书里仅在「主冲之支」的定位序列里提到流月，本期不实现）
- 岁运与原局之外的第三层（如小运）
- 任何对**原局**结论的改动
- **分项断事**：事业/财运/健康等分类吉凶结论。书里此类内容以命例形式出现、无成文规则，做成产品输出无法对拍（见 FR-016a）
- **引擎合成的吉凶结论**：不出吉/凶档位、不给事件断语——书 下 4418 的四档总则本期**不落地为合成结论**；大运层与流年层的判断**并列罗列**，由使用者判断（见 FR-016a/016c 与 Assumptions 的分歧登记）
- **书 下 4207「用神不随流年变」的通则**：本期按用户裁定改为「用神随流年重判」（见 FR-016b 与 Assumptions 的分歧登记），不复核该书条
- **流年当值太岁的生克权例外**：012 规格澄清的两条（流年太岁纵弱仍保有生克权；日主为流年太岁时仍能作用）**本期不实现**，流年按常规生克权规则走——**登记为未尽**（自 012 起即遗留，见 Clarifications）

## Clarifications

### Session 2026-09-21

- Q: 岁运推导结论是否随命盘保存？ → A: **不落库**，按需实时计算。原局结论照旧保存、照旧按口径版本重算；岁运结论每次打开或切换大运/流年时现算，不进记录。
- Q: 现有原局结论页上已渲染的「用神随大运变化」一行（其内容本身属岁运结论），本期是否允许变化？ → A: **允许变化**。该行不属「原局不变」的保护范围；须保护的是原局那几项（旺度档位、五行旺度、格局、用神/喜神/忌神、调候、格局层次、依据说明）。且同一命盘的**同一步大运**在原局页与岁运页 MUST 给出一致的用神结论。
- Q: 年度判读的输出深度？ → A: **（已被本会话末条推翻）** 原定「仅吉凶档位 + 依据（吉/凶/有喜有忧/平运 四档）」；末条裁定改为**引擎不合成吉凶**，两阶段判断并列罗列。**「分项断事不做」这一半仍然有效**，由 FR-016a 承接。
- Q: 岁运推导页可以从哪些命盘进入？ → A: **新排盘与已保存记录都能进**。记录详情页提供入口；因岁运结论不落库，从记录进入时须**由该记录的输入信息当场重推大运与流年**再计算（后经 2026-09-21 修订扩为两个新页面，见下条）。无出生日期的记录按 FR-025 降级提示。
- Q: 012 新增的两项喜忌输出（调候量化、格局层次）是否也随大运重判？ → A: **两项都随大运重判**。二者都建立在「格局 + 旺度」之上，而本期已把大运接入后者；若冻结在原局口径，页面上会出现「格局按大运重判、层次仍按原局」的自相矛盾，且无法用依据解释（违反 SC-005）。它们在岁运页与原局页显示不同结论，属 FR-022a 已确立的「岁运结论允许变化」。

- Q: 流年的作用边界——它「作用于原局」到哪一步？ → A（用户自定义，**推翻原「流年不参与强度计算」**）：**流年也参与关系和度数**。计算**分阶段、一步一步**做——先算大运，再在「已含大运」的结果之上算一轮流年；三个阶段各成**一个页面**：**原局页 / 加入大运后的页 / 加入流年后的页**。此裁定与书一致（书里流年本是一支，且在四墓库藏干 上 399-403/449-451/491-497、未克申酉 上 2309、辰戌丑未相冲 下 1735-1752 三处有**独立于大运**的度数档），原先因「不参与强度」而排除的那三处**回到范围内**。
- Q: 用神是否随流年变？ → A: **随流年重判**。流年既已参与关系与度数，用神 MUST 按该年重判后的旺度与格局**重新取用**，与格局/取用同口径——不得出现「旺度与格局随流年重判、用神却冻在大运层」的内部不一致。**此条推翻了书 下 4207 的通则**（「用神随大运的变化而变化，一般不会随流年的变化而变化」）与先前规格里「用神只随大运变」的写法；书所指「中和状态最易变」的特例（下 4002）在本裁定下已自动被覆盖。
- Q: 年度判读锚定在哪个「用神」上？ → A: **（已被下一条推翻）** 原定「两个用神并列、判读锚定大运基准」，系为规避破格年判反而设；下一条裁定改为**不做合成**，故锚定问题自然消解。
- Q: 年度判读该由哪些信号决定（是否合成单一吉凶）？ → A（用户自定义）：**不做合成**。**大运阶段给出的判断（用神、喜神、忌神、旺度、格局、调候、层次……）与流年阶段给出的判断，一律并列罗列**，**不合成单一的吉凶结论**，由使用者自行判断。**原用于论证的守门例 书 下 4246 经用户裁定「该案例本身不对」，不再作为依据**（其相关要求同步撤销）。
- Q: 流年之干是否参与天干层面的判定（五合／争合）？ → A: **与大运同构**——参与天干五合（含换字后按 012 期 C26-29 重判地支），但**不与原局之干构成争合**（沿用 FR-012 对岁运之干的限制）。原规格把天干层面只写给了大运（FR-012），流年之干无着落，此条补齐。
- Q: 流年当值太岁的生克权例外是否实现？ → A: **本期不实现**。012 规格澄清里那两条（「流年太岁纵使太弱仍保有一定生克权」、「日主无生克权但为流年太岁时仍能作用」，见 `012/spec.md:195,197`）**均未落地，也不在本期承接**——流年按常规生克权规则走，两条登记为**未尽**（它们自 012 起即遗留）。
- 【plan 阶段确认，2026-09-21】两项架构口径已拍板，落地见 [contracts/suiyun-v2.md](contracts/suiyun-v2.md)：① **命盘图的岁运维度改为只消费后端产出**（前端流年本地判定副本退役）——这是 FR-024 / SC-008「来源标注无歧义」得以成立的前提；② **`records` 保存路径取宽松解读**——本期新增结论不落库、既有持久化行为保持现状（FR-026）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 岁运介入后的关系与旺度判得对 (Priority: P1)

用户为某命盘选定一步大运，看到的关系判定与旺度不再是「只按原局月令」的结果，而是把该步大运真正算进去：化神是否当令改看**月令与该步大运的综合状态**；大运支作为一支参与刑冲合害（受既有的让位规则约束）；大运支能把原局本来相隔、因而不作用的支「拉近」为相邻，从而让原本不成的关系成立。每一条都能读出它依据了哪条书文。

**Why this priority**: 这是本期的核心价值，也是当前最实质的错误来源——只要盘里有大运，凡涉及「化神是否当令」的判据都会因为只看原局月令而判错。其余故事都建立在它之上。

**Independent Test**: 取书中明确带大运的算例逐步断言即可独立验收。代表性的三类：① 大运补成局（书 上 3502：原局亥卯未因卯不相邻不成，进乙亥运后「亥卯未变得相邻紧贴」，合化木成功）；② 综合状态翻转化神当令与否（书 上 916/934：金在原局囚、在大运相，折中为休，故酉丑合化不成功）；③ 四库逢冲（书 下 1912：进辛丑运后辰戌丑未四库齐而成局）。

**Acceptance Scenarios**:

1. **Given** 一个原局中存在「化神不当令、故合而不化」的盘的命盘，且某一步大运使该化神在该运处于当令之地，**When** 计算该步大运，**Then** 该关系在该步按**综合状态**重判，并在依据里写明月令状态、大运状态与折中结果
2. **Given** 某步大运的干支与原局某支构成刑冲合害，**When** 计算该步，**Then** 该关系与大运支一同判定，且大运支受与其它支相同的让位规则约束（被更高优先级关系占用时不再参与）
3. **Given** 原局中两支相隔、因而不发生作用的盘，**When** 引入一支与其中一支同类或为其本身的大运，**Then** 该两支在该步变为相邻、原本不成的关系成立，且依据里注明是由岁运桥接
4. **Given** 任一命盘，**When** 查看任一步大运的结论，**Then** 每条关系与度数变化都能追溯到具体依据（哪条书文、折中状态算式、参与柱位）

### User Story 2 - 在「已含大运」的结果之上再加一轮流年判定 (Priority: P2)

用户在某一步大运之上逐年查看：该年的流年干支**作为一支**同样参与刑冲合害与度数增减（适用流年**自己的**度数档，与大运档不同），据此重判该年的关系、旺度、格局与取用。页面上**把大运阶段的判断与流年阶段的判断逐项并列罗列**（各自的用神/喜神/忌神、旺度、格局、调候、层次，各标来源），**引擎不给吉凶结论**——由使用者自己对照两列来判断这一年。用户能确认这是**分阶段的增量**：把流年这一层拿掉，结论就退回该步大运页；把大运也拿掉，就退回原局页。

**Why this priority**: 用户明确要求「后面再算一轮流年」且「流年也参与关系和度数」。它是三阶段模型的第二阶段——没有它，第三页无从谈起；但它必须**建立在** P1 的大运层之上，故排在 P1 之后。

**Independent Test**: 取书中带流年算例逐年断言即可独立验收（如 下 1735-1752 辰戌丑未冲的「临流年」诸档、上 399-403 丑「在流年或流日出现时含水 1 度」 vs 「在大运出现时含水 2 度」、上 2309 未克申酉「临流年减 1/3」vs「临大运减半」）；并断言去掉流年后结论**回到**该步大运页的值。

**Acceptance Scenarios**:

1. **Given** 某步大运下选定的某一年，**When** 计算该年，**Then** 输出含该流年的关系判定、旺度、格局与取用，且每条可追溯到依据
2. **Given** 流年页，**When** 用户查看结论，**Then** 大运阶段与该年流年阶段的同名判断**逐项并列**（各自的用神/喜神/忌神、旺度、格局、调候、层次），各标来源阶段，且**页面上没有任何引擎合成的吉凶档位或事件断语**
3. **Given** 该年流年之支落在四墓库或与未克申酉相关，**When** 计算该年，**Then** 该支适用**流年独立于大运**的度数档，依据中写明所据档位
4. **Given** 同一步大运下的两个不同流年，**When** 分别计算，**Then** 二者的结论**各自独立**——流年参与关系与度数，故两项结论允许不同；差异须能从「流年支参与/不参与哪些关系」解释
5. **Given** 某年的流年页结论，**When** 移除该流年、只看该步大运，**Then** 结论**回到**大运页的值（分阶段增量成立，流年层不污染大运层）
6. **Given** 该年流年之支被该步大运合、冲或合绊住，**When** 计算该年，**Then** 按「命 → 运 → 岁」的门控处理——依据中写明该流年被大运所制（书 下 4430/4468）

### User Story 3 - 三个阶段各成一页：原局页 / 加入大运页 / 加入流年页 (Priority: P3)

用户在同一个命盘上，能沿三个阶段依次下钻，每一阶段有**自己的页面**：① **原局页**（现有旺度与喜忌详情页，不动）；② **加入大运后的页**——选定一步大运，看该步含大运的全部推导；③ **加入流年后的页**——在该步之下选定一年，看该年含流年的全部推导。三个页面层层递进、互不覆盖，任一页都能看出「它是在哪一阶段的基础上算出来的」。两个新页面的入口都在新排盘结果页与已保存记录详情页。

**Why this priority**: 用户明确要求「分为不同的页面……最终生成原局页面、加入大运后的页面、加入流年后的页面」。分页是这套分阶段模型的外在形态——阶段之间的依赖关系只有靠页面层次才表达得清，也才能保证前一阶段的改动不污染后一阶段。

**Independent Test**: 对同一命盘依次打开三页，核对「三页结论 = 三个阶段的增量」；切换数步大运与数个流年，核对页面结论与引擎输出一致；同时确认原局页内容与本次改动前**逐项一致**。

**Acceptance Scenarios**:

1. **Given** 一个已排出的命盘，**When** 用户从结果页进入「加入大运」页，**Then** 当前所处大运默认选中，并展示该步含大运的推导结论
2. **Given** 「加入大运」页的某步大运，**When** 用户进入「加入流年」页，**Then** 默认选中该步内的当前年份（不在区间内则取该步第一年），并展示该年含流年的推导结论
3. **Given** 「加入流年」页，**When** 用户切换该步内的其它年份，**Then** 结论按新的流年重判（流年参与关系与度数），且依据可读
4. **Given** 「加入大运」页，**When** 用户切换大运步，**Then** 关系判定、旺度、格局、取用、调候、格局层次整体切换为该步的
5. **Given** 一条已保存的命盘记录，**When** 用户从其详情页进入两个新页面，**Then** 页面按该记录的输入信息**重推大运与流年**后再计算（不依赖记录里是否存过岁运结论）
6. **Given** 原局结论页，**When** 用户查看同一命盘，**Then** 其**原局部分**（旺度档位、五行旺度、格局、用神/喜神/忌神、调候、格局层次、依据说明）与本次改动前逐项一致；页上的「用神随大运变化」一行属岁运结论，允许变化，且与「加入大运」页对同一步大运给出一致结论
7. **Given** 一个没有出生日期、无法推算起运的命盘（无论新排盘还是已保存记录），**When** 用户尝试进入两个新页面，**Then** 明确提示该盘无法进行岁运推导，其余页面与内容照常可用

### User Story 4 - 既有结果与记录保持可用且不变 (Priority: P4)

本次改动不得使任何既有命盘的**原局结论**发生变化：已保存的历史记录打开后，其原局部分与保存时逐项一致；新排的盘在原局部分上也与改动前逐项一致。含大运的那部分结论（含原局页上的「用神随大运变化」一行）属**岁运结论**，允许因本期的判定改进而不同，并须在页面上可区分。

**Why this priority**: 用户明确要求「保留当前计算结果」。结论的稳定性是这个工具可信度的基础——若同一命盘两次打开给出不同结论，用户无法使用。

**Independent Test**: 取改动前的一批命盘（含已落库的历史记录），改动后重新计算并逐项比对原局结论；对含岁运的部分单独比对并记录差异。

**Acceptance Scenarios**:

1. **Given** 一批改动前已保存的命盘记录，**When** 改动后重新打开，**Then** 原局结论（旺度档位、五行旺度、格局、用神/喜神/忌神、调候、格局层次、依据说明）逐项一致
2. **Given** 同一命盘，**When** 分别用改动前后的版本计算原局结论，**Then** 结论完全相同
3. **Given** 含岁运的既有结论，**When** 改动后重新计算，**Then** 结论允许不同，但页面能按三阶段区分「属原局」「属大运」「属流年」

---

### Edge Cases

- **无出生日期（四柱输入模式）**：无法推算起运，故无大运步骤、亦无流年。岁运推导整体不可用，页面须明示原因并降级，不得报错或显示空结论。
- **未起运**：出生后尚未交入第一步大运时段的命盘，须明确「尚未起运」而非默认用第一步大运顶替。
- **时辰不详（缺时柱）**：原局已按既有约定降级（时干不参与天干生克、时支不参与关系判定）；岁运介入后此降级须保持一致，不得因岁运存在而把时柱重新算进来。
- **大运支与原局支构成多个关系**：须按既有让位规则裁决，且须保证「化神一致者可并存」的例外同样适用于岁运参与的关系。
- **大运支恰好与原局某支同类**：须区分「同类使相隔之支变为作用」（生克与相合的处理不同），不得一概而论。
- **流年落在该步大运的哪一段**：大运十年为一体，干支同时全程有效，不采用「前五年天干、后五年地支」的分管说法。
- **同一步大运下不同流年给出不同结论**：这是本期**预期**的行为（流年参与关系与度数），不再是「应当相同」；页面须让用户能看出差异来自哪条由流年引入的关系。
- **流年之支与大运之支同类**：须区分「同类使相隔之支变为作用」（生克与相合的处理不同，FR-008），且两阶段各自的桥接效果须分阶段记录，不得混入前一阶段。
- **同一命盘反复打开**：结论必须确定、可复现，不得因缓存或计算顺序产生差异。

## Requirements *(mandatory)*

### Functional Requirements

**岁运的介入判据**

- **FR-001**: 系统 MUST 判定某条关系是否存在「岁运介入」，即该关系的参与支中至少有一支出现在大运或流年上；岁运介入时，该关系成立条件中「化神是否当令」一项 MUST 改用**综合（折中）状态**判定，而非仅看原局月令。
- **FR-002**: 综合状态 MUST 由**月令状态参数与大运状态参数取平均**得出，参数取值为 旺=1、余气=2、相=3、休=4、囚=5、死=6，**平均后 ≤3 为当令、>3 为失令**。
- **FR-003**: 综合状态 MUST **只取月令与大运**，**流年 MUST NOT 参与折中**——即使流年之支加入了某关系，折中仍只按月令与大运计算。
- **FR-004**: 当原局月令的化神状态本身已被改变（如月令之支被合化）时，系统 MUST 取**月令被改变后的状态**再与大运参数平均；大运状态被改变时同理。

**岁运支作为一支参与关系**

> 本组的「岁运之支/干」按术语表定义为**大运与流年两者**；两组在相邻性与参与规则上**同规**，差别只在度数档（FR-009 / FR-015）与折中（FR-017a）。

- **FR-005**: **大运与流年**之支 MUST 视为与原局**任何一柱**均相邻——不适用原局内「相隔不作用」的柱距限制。两者的天干同理。
- **FR-006**: **大运与流年**之支 MUST 作为一支参与刑冲合害的判定，并受与其它支**相同**的让位规则约束（被更高优先级关系占用时不再参与其它关系）。
- **FR-007**: 当原局两支因相隔而不发生作用，而岁运介入了一支与其中一支同类或为其本身的支时，系统 MUST 使该两支在该步变为**可作用**。（书：不相邻的地支不作用，但如果中隔的地支是它们其中的一个则可作用；岁运有它们的同类或它们本身介入则变成作用。）
- **FR-008**: 上述「变为可作用」对**生克**与**相合**的处理 MUST 分别对待：中隔之支为同类时只对生克有效，对相合无效。
- **FR-009**: 系统 MUST 按位置区分度数档：受克者**临月令**与**临大运**适用不同的度数（书里六冲分列这两档，如生地冲 1 / 临月令 1.5 / 临大运 1.25），且**主克者的加重档优先于临大运档**。六冲**没有「临流年」档**（书 下 1605/1651 只有月令与大运两档）——流年之支落在六冲中时 MUST 按基准档处理，MUST NOT 自行外推一个流年档。

**大运的度数贡献**

- **FR-010**: 系统 MUST 按运支所处的状态对五行旺度做增减（旺 +2、余气 +1.5、相 +1、休 −1、囚 −1.5、死 −2），并在运干有同类相助或通根于运支时依理叠加；两类增减叠加后即为该五行在大运的旺度。
- **FR-011**: 大运之支**自身所含的藏干度数** MUST 计入该步的旺度池（与四柱之支同等对待），不得只按运支状态增减而忽略其藏干。
- **FR-012**: 大运之干支 MUST 一并参与天干层面的关系判定（含五合与争合）；且大运之干 MUST NOT 与**原局之干**构成争合——该限制**只针对原局之干**：大运之干与**流年之干**之间**可以**争合。
- **FR-012a**: 大运之干参与天干五合而化成功者，MUST 按 012 期 C26-29 的口径以**换字后的干**重判一趟地支；依据中须写明该干参与/未参与哪些天干关系。（流年侧同构要求见 FR-014a。）
- **FR-013**: 大运的干支 MUST 视为**十年一体**、同时全程有效，**不得**采用「前五年天干、后五年地支」的分管说法。

**流年的参与（第三阶段）**

- **FR-014**: 流年之支 MUST **作为一支参与刑冲合害的判定**，与**大运之支同规则**（相邻性、参与范围、让位约束一并适用 FR-005~FR-008），**差别仅在度數档**（见 FR-015）与**折中**（见 FR-017a）。
- **FR-014a**: 流年之干 MUST **与大运之干同构**地参与天干层面的判定——可参与**天干五合**（化成功换字者，MUST 按 012 期 C26-29 的口径以换字后的干重判一趟地支），但 MUST NOT 与**原局之干**构成**争合**（限制范围与 FR-012 同：只针对原局之干，与大运之干之间可以争合）。依据中须写明该年天干参与/未参与哪些天干关系。
- **FR-015**: 当流年之支落在**四墓库**、或涉及**未克申酉**、或与**辰戌丑未相冲**相关时，MUST 适用**流年独立于大运**的度数档（书 上 399-403 丑「在流年或流日出现时——丑含水 1 度」vs「在大运出现时——含水 2 度」；上 2309 未克申酉「临流年减 1/3」vs「临大运减半」；下 1735-1752 辰戌丑未冲的 a/b/c/d 诸档），MUST NOT 与大运档混用；依据中须写明所据档位。
- **FR-016**: 系统 MUST 对**该步大运覆盖范围内的每一个年份**（即该步十年）逐流年**重判关系、旺度、格局与取用**，作为第三阶段的结论，并 MUST 把**大运阶段的判断与流年阶段的判断并列罗列**在同一页面上，供使用者对照。
- **FR-016a**: 系统 MUST **不合成单一吉凶结论**——MUST NOT 输出由引擎判定的吉/凶档位或事件断语。（书 下 4418 的「用神到位则吉、忌神到位则凶」四档总则**本期不实现为合成结论**，差异登记入册；判断留给使用者。）MUST NOT 输出**分项断事**（事业、财运、健康等分类结论）。
- **FR-016b**: **用神随流年重判**——流年既参与关系与度数，系统 MUST 按该年重判后的旺度与格局**重新取用神、喜神、忌神**，与格局/取用同口径；MUST NOT 沿用大运层的用神。**此条与书 下 4207 的通则相悖**（书谓用神只随大运变），系 2026-09-21 用户裁定，差异登记入册；书所指「中和状态最易变」的特例（下 4002）在本裁定下已自动覆盖。
- **FR-016c**: 并列罗列时，**两阶段的同类判断 MUST 成对呈现且各自标明来源阶段**——该步大运的用神/喜神/忌神/旺度/格局/调候/层次（标为**属大运**）与该年流年重判后的同名各项（标为**属流年**）逐项对照，使使用者能一眼看出「加流年之后哪几项变了、分别变成什么」。MUST NOT 只给其中一阶段，也 MUST NOT 用一阶段的值覆盖另一阶段。
- **FR-017**: **阶段独立性**：流年层 MUST NOT 改变大运层的结论——对同一命盘、同一步大运，**移除流年后的结论 MUST 逐项回到「加入大运」页的值**；同理，移除大运后 MUST 回到原局页的值。三页的关系是**层层递进的增量**，不是并列的三套结论。
- **FR-017a**: 流年 MUST NOT 参与**综合（折中）状态**的计算——即使流年之支加入了某关系，折中仍只按月令与大运（书 上 3213 铁证：流年午火明明加入午未合局，算式仍只取月令与大运平均）。**这是书自己的口径，不是简化**，故虽流年参与关系与度数，仍不改 FR-003。

**岁运与原局的先后与优先级**

- **FR-018**: 岁运介入时，关系的优先次序 MUST 沿用原局的同一套十八级次序，**不得**另立一套岁运专用次序。
- **FR-019**: 系统 MUST 按「命 → 运 → 岁」的**分阶段**制约关系处理三者：先算大运（改变原局的结构——相邻关系、合化、用神），**再在「已含大运」的结果之上算流年**。流年之支若被该步大运合、冲或合绊住，则视为**作用不到原局**（书 下 4430「运制约岁」、下 4468「流年为吉如果不能让命局接受得到则以凶论」）；此门控的判定结果 MUST 写入依据。
- **FR-020**: 判定「主冲之支」时 MUST 按出现顺序取**后出现者**（原局 → 大运 → 流年），前面出现的为受冲之支。

**页面与兼容**

- **FR-021**: 系统 MUST 提供**三个层层递进的页面**，对应三个阶段：① **原局页**（现有旺度与喜忌详情页）；② **「加入大运」页**——选定一步大运，展示该步含大运的全部推导；③ **「加入流年」页**——在该步之下选定一年，展示该年含流年的全部推导。三页 MUST 各自标明「处于哪一阶段」，并可从任一页看出它是建立在哪一阶段之上。
- **FR-021a**: 两个新页面 MUST 可从**两处**进入：新排盘的结果页，以及**已保存记录的详情页**。因岁运结论不落库，从记录进入时 MUST 由该记录的输入信息当场**重推大运与流年**后再计算——不得依赖记录中任何已保存的岁运结论。
- **FR-021b**: 「加入大运」页 MUST 包含**调候量化**与**格局层次**两项，且二者 MUST 按该步大运同口径重判——不得出现「格局/取用按大运重判、而调候或层次仍按原局」的内部不一致；每条均须给出可读依据。
- **FR-021c**: 「加入流年」页 MUST 把**大运阶段与流年阶段的判断逐项并列罗列**（FR-016c），并含该年所依据的关系、旺度、格局与取用结论及其依据；调候与格局层次 MUST 按该年同口径重判（与 FR-021b 一致），并标明其相对大运阶段是否变化。
- **FR-022**: 现有**原局页** MUST 保持可用，其**原局部分**（旺度档位、五行旺度、格局、用神/喜神/忌神、调候、格局层次、依据说明）MUST 内容不变；含大运与含流年的结果 MUST NOT 混入原局部分。
- **FR-022a**: 原局页上「用神随大运变化」一行属**岁运结论**，MUST NOT 受上述「内容不变」约束——本期把大运接入判定后该行允许变化。同一命盘的**同一步大运**在原局页与「加入大运」页 MUST 给出一致的用神结论，不得并存两套大运口径。
- **FR-023**: 系统 MUST 保证原局结论（不含岁运者）在本次改动前后**逐项一致**，包括已保存的历史记录打开后的原局部分。
- **FR-024**: 三页 MUST 能区分结论的**来源阶段**——「属原局」「属大运」「属流年」三者不得混同；同一项结论不得同时标为两个来源。
- **FR-025**: 无出生日期（无法推算起运）、尚未起运、时辰不详这三种命盘，两个新页面 MUST 按各自情况降级并明示原因，其余功能不受影响。
- **FR-026**: 含大运与含流年的推导结论 MUST **不随命盘记录持久化**——按需实时计算；原局结论的保存、读取与「口径变更则重算」路径 MUST 保持不变。

### Key Entities

- **大运步**：一步大运的干支、起止年份与起始年龄；其上挂有该步含大运的完整推导结论（第二阶段），以及该步覆盖的各流年。
- **流年**：某一步大运下的一个年份，含该年干支；其上挂有该年含流年的完整推导结论（第三阶段）。流年之支**参与关系与度数**，故它携带完整的关系与度数信息。流年页同时并列呈现**大运阶段与流年阶段的同名判断**，供使用者对照。
- **综合（折中）状态**：某一五行在「月令 + 大运」下的平均状态，含当令/失令结论，是岁运介入时关系成立条件的判据。**只取月令与大运，流年不参与**。
- **阶段结论**：三个阶段各产出一份完整推导——**原局结论**（现有，保持不变）、**含大运的结论**（第二阶段）、**含流年的结论**（第三阶段）。三者**层层递进**：后一阶段以前一阶段的结果为基础，移除后一阶段须逐项退回前一阶段的值（FR-017）。均**按需实时计算、不落库**；互不覆盖，也不改写已保存的记录。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 书中带大运/流年的算例中，凡「原局判不成、岁运介入后判成」（或反之）的典型例子，本期后**全部**能给出与书一致的结论——以整理出的岁运算例清单为准，清单逐条列出一致/差异，差异项必须能从依据解释。
- **SC-002**: 用户能从**新排盘结果页**与**已保存记录详情页**两个入口进入「加入大运」页与「加入流年」页，并在页内完成「切换大运步 → 切换年份 → 读到该年判读与依据」的完整流程，无需离开页面体系。
- **SC-003**: 同一命盘的**原局部分**结论在改动前后 **100% 逐项一致**（含已保存的历史记录打开后的原局部分）。「用神随大运变化」一行不在此列——它属岁运结论，允许变化。
- **SC-004**: **阶段独立性 100% 成立**——对同一命盘、同一步大运，移除流年后的结论逐项**回到**「加入大运」页的值；移除大运后逐项**回到**原局页的值。三页是层层递进的增量，不是三套并列结论。
- **SC-005**: 两个新页面上的每一条关系与度数变化都能追溯到至少一条依据说明；无法追溯的结论数为 **0**。
- **SC-006**: 无出生日期、尚未起运、时辰不详三类命盘进入两个新页面时，均给出明确提示且**不报错**（页面其余部分正常）。
- **SC-007**: 同一命盘的任一步大运，在**原局页**与**「加入大运」页**上的用神结论 **100% 一致**（不一致的步数为 0）——不存在同一命盘、同一步大运并存两套大运口径。
- **SC-008**: 结论的**来源阶段标注 100% 无歧义**——任一结论要么标为属原局、要么属大运、要么属流年，不得同时标两个来源，也不得来源不明。
- **SC-009**: 流年页上**大运阶段与流年阶段的判断 100% 成对罗列**——两阶段各自的用神/喜神/忌神/旺度/格局/调候/层次逐项可见、各标来源；引擎合成的吉凶结论数为 **0**。

## Assumptions

- **三阶段模型**（2026-09-21 用户修订后确立）：**原局 → 加入大运 → 加入流年**，逐阶段累积、一步一步算。大运与流年**都参与关系与度数**。这是本期的主干，取代原先「流年不参与强度计算」的划分。
- **流年参与关系与度数**：与书一致——书里流年本是一支，并在四墓库藏干、未克申酉、辰戌丑未相冲三处有**独立于大运**的度数档，本期按书实现（FR-015）。六冲无流年档，故落基准（FR-009）。
- **折中状态仍只取月令与大运**：虽流年参与关系与度数，书仍明确折中只取月令与大运（上 3213 的算例里流年午火明明加入合局、算式却没有它）。**这是书自己的口径，不是本期简化**，故 FR-003 保持不变。
- **用神随大运变，也随流年重判**（2026-09-21 用户裁定，**推翻书 下 4207 的通则**）：书谓「用神随大运的变化而变化，一般不会随流年的变化而变化（但有特例）」，本裁定取「随流年重判」——理由是流年既已参与关系与度数，用神若冻在大运层就会出现「旺度与格局随流年重判、用神不动」的内部不一致，且该矛盾无法用依据解释。书所指「中和状态最易变」（下 4002）的特例在本裁定下已自动覆盖。**与书的分歧登记入册**，留待后续期次复核。
- **引擎不做吉凶合成，判断留给使用者**（2026-09-21 用户裁定）：大运阶段与流年阶段的判断**并列罗列**（FR-016c），引擎**不合成**吉凶档位、不给事件断语（FR-016a）。这否定了先前「判读锚定大运基准用神」的方案，也否定了书 下 4418 四档总则的落地形式（差异登记入册）。**连带**：原用于论证锚定方案的守门例 书 下 4246 经用户裁定「该案例本身不对」，已从规格中撤除，不再作为依据。
- **流年之干与大运同构**（2026-09-21 用户裁定）：参与天干五合、不与原局之干争合（FR-014a），使三阶段在天干层面的处理一致。
- **流年太岁生克权例外不实现**（2026-09-21 用户裁定）：012 规格澄清里那两条自 012 起即遗留、从未落地，本期仍不承接，**登记为未尽**；流年按常规生克权规则判。后续期次若处理，须同时定义「保有一定生克权」的量（书未给）。
- **大运十年一体**：不采用「前五年天干、后五年地支」的分管说法。
- **复用既有口径**：换字后重判、十八级让位、「化神一致者可并存」的例外、时辰不详的降级约定、四柱输入模式的降级约定，均沿用 012 期的既有裁定，本期不重新讨论。
- **流年计算范围**：按需计算——用户选中某步大运算该步覆盖的各流年；不预先计算全部命盘的全部年份。
- **岁运结论不落库**（2026-09-21 用户确认）：岁运推导结论按需实时计算、不进记录。原局结论的保存与「口径变更则重算」机制沿用既有设计不改结构。**注意**：本期改动了判定代码，既有机制会据引擎版本变化**重算既有记录**——重算后的**原局部分必须与保存时逐项一致**，这正是 FR-023 / SC-003 的由来（原局路径未被改动，故可保证）。既有记录中若已保存过含大运的结论，本期不改其存储结构；页面须按三阶段区分「属原局」「属大运」「属流年」（FR-024）。
- **对拍基准**：本期须把书中带大运/流年的算例整理成可复跑的样本清单（含来源章节、四柱、大运、书中原始结论），作为 SC-001 的比对基准；书里带明确结论的命例中相当一部分包含大运，须从中筛出岁运相关的部分。
