## 2. 三阶段模型（一句话理解本期）

```
阶段 1 原局         = 现有 compute_strength(pillars)              → 原局页（一字不改）
阶段 2 加入大运      = 阶段 1 + 该步大运参与                      → 「加入大运」页
阶段 3 加入流年      = 阶段 2 + 该年流年参与                      → 「加入流年」页
```

**层层递增**：把流年拿掉就退回阶段 2；把大运也拿掉就退回阶段 1（FR-017 / SC-004）。引擎**不给吉凶结论**，
两阶段判断**并列罗列**，判断由使用者做（FR-016a / FR-016c）。

## 5. 最容易踩的五个坑

1. **把流年接进折中**。流年确实进了关系层与度数，所以最容易顺手把折中也接上——但书明写折中只取月令与大运
   （上 3213 的算例里流年午火明明加入合局、算式却没有它）。须有**专门测试**守住 FR-003/FR-017a。
2. **靠下标巧合实现「岁运与任何柱相邻」**。伪列排在列尾，`_adjacent`/`_touching` 已豁免，但 `_ju_runs`/`_contiguous`
   没有——书 上 3502 的桥接**实测不复现**就是这个原因。改的是**语义**，不是加一个 `if`。
3. **把大运的效应算两遍**。`analyze_step` 是 `compute_strength(含运) → apply_dayun_delta` 两步，与书 上 847 的
   ①② 对应，**不是双扣**。但运支**自身藏干**（书 上 884/900/901）现在完全没进池——这才是缺的那一半。
4. **顺手重构**。本期范围大，但宪法 III/IV 明确：不得重构旧引擎、不得改动排盘上游、不得动既有的
   记录持久化行为（已确认②为宽松解读：新增结论不落库、既有行为保持现状）。
5. **合成吉凶**。FR-016a 禁止引擎输出吉凶档位——契约里出现 `verdict` 一类字段即为违宪（同时也是
   上一轮 clarify 里被明确否决的方案）。

## 6. 术语速查

| 术语 | 含义 |
|---|---|
| **岁运** | 大运 + 流年的合称（干支层面） |
| **综合（折中）状态** | (月令参数 + 大运参数) / 2，参数 旺1/余气2/相3/休4/囚5/死6，≤3 当令。**流年不参与** |
| **阶段** | 原局 → 加入大运 → 加入流年，三阶段各成一页 |
| **来源阶段** | 属原局 / 属大运 / 属流年——每项结论只标一个（FR-024） |
| **桥接** | 岁运介入使原局相隔之支变为可作用（书 上 1541 / 下 1684） |
| **门控** | 命 → 运 → 岁：流年被该步大运合/冲/合绊住则作用不到原局（书 下 4430/4468） |
| **六冲的临月令/临大运档** | 生地冲 1 / 1.5 / 1.25；子午卯酉冲 1 / 2 / 1.5（另有死地 1.8）。**无流年档** |
| **流年独立档（仅三处）** | 四墓库藏干（上 399-403/449-451/491-497）、未克申酉（上 2309）、辰戌丑未冲（下 1735-1752） |
