# Feature Specification: 命盘图（干支 · 流通 · 宫位 · 六亲 可视化）

**Feature Branch**: `007-bazi-relations-diagram`  
**Created**: 2026-08-14  
**Status**: Draft  
**Input**: User description: "排盘结果页加上 当前八字的干支、流通、宫位、六亲 以图示的方法容易让用户查看"

## Clarifications

### Session 2026-08-14

- Q: 五行「流通」在命盘图中怎么呈现？ → A: **干支双层箭头** —— 天干层与地支层分别在相邻柱之间画箭头，按相生(绿)/相克(红)/比和(灰)着色，直观展示五行之气在四柱间的流动
- Q: 图示的信息密度与「六亲/藏干」怎么呈现？ → A: **藏干折叠可点开** —— 主图展示天干十神 + 宫位六亲，地支显示五行色块；地支藏干与藏干十神默认折叠，点开对应柱展开明细
- Q: 流通箭头对色盲用户的可读性？ → A: **颜色 + 文字标注** —— 每条箭头除颜色外还带「生/克/比」汉字标签，红绿色盲用户同样可读
- Q: 干支/流通/宫位/六亲 如何组织呈现？ → A: **四个 tab**（关系 / 流通 / 宫位 / 六亲），默认选中「关系」；切换 tab 展示各自独立的信息 —— 关系 tab=干支/藏干合冲连线图（含大运流年）、流通 tab=干支双层箭头、宫位 tab=宫位映射表、六亲 tab=本命十神→六亲+图例
- Q: 「关系」tab（原干支 tab）的呈现与范围？ → A: **八字行 + 上下两层连线**（参考"栏江网"式）：中间一排八字不变（大运/流年/年/月/日/时，干在上、支在下），**上方**画天干关系连线、**下方**画地支关系连线；纳入**当前选中的大运/流年**（跟随横条联动）。仅**天干对天干、地支对地支**（不含藏干关系、不跨层）。天干：五合、四冲、相生、相克；地支：六合、六冲、相刑（子卯/寅巳申/丑戌未/辰午酉亥自刑）、六破、六害，并支持**三合/三会成局**
- Q: 关系类型如何筛选显示？ → A: 顶部提供**多选**关系类型筛选，分**天干/地支两行**：天干=相生/相克/五合/合化/相冲，地支=三会/三合/六合/相冲/相刑/六害/相破；默认不勾选（不画连线），勾选某类才显示该类连线，可多选。下方固定罗列**当前命盘存在的关系汇总**（按类型去重），不受筛选影响。**藏干**显示在地支下方（纯展示，不参与关系）；**合化**从五合拆出为独立类型
- Q: 关系图的横向布局？ → A: **一屏内显示**——大运/流年/年/月/日/时全部收进当前宽度，SVG 按容器宽度百分比均分列、自适应缩放，**不左右拉动**（不横向滚动）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 四 tab 导航 + 干支 tab（四柱干支 + 五行 + 藏干） (Priority: P1)

用户打开排盘结果页，看到一张「命盘图」卡片，顶部有四个 tab（干支 / 流通 / 宫位 / 六亲），默认停在「干支」tab：四个柱（年/月/日/时）以图示呈现，每柱显示干支并按五行着色，日主（日柱天干）高亮，点击地支可展开藏干明细。切换到其余 tab 展示各自独立的信息。

**Why this priority**: 这是图示的核心价值——把原本散落在表格里的四柱、宫位、六亲信息整合成一张可读的图，是用户诉求的主体，也是后续流通箭头与藏干明细的载体。

**Independent Test**: 任意排出一张盘，结果页即可看到四柱节点 + 宫位标注 + 天干十神，内容与四柱明细表完全一致；时辰不详的盘（缺时柱）图正常显示其余三柱并提示。可独立验证。

**Acceptance Scenarios**:

1. **Given** 一张已排出的命盘，**When** 打开结果页，**Then** 看到「命盘图」卡片，包含年/月/日/时四个柱节点，每柱展示干支
2. **Given** 命盘图四柱，**When** 查看每柱，**Then** 天干与地支均按五行着色（木/火/土/金/水对应标准五行色）
3. **Given** 命盘图四柱，**When** 查看每柱标注，**Then** 年柱标注「祖上宫」、月柱标注「父母宫」、日支标注「配偶宫」、时柱标注「子女宫」，且每柱显示以日主为基准的天干十神
4. **Given** 命盘图，**When** 查看日柱，**Then** 日主被高亮标识（如描边/底色强调），与其余十神区分
5. **Given** 一张缺时柱的命盘（时辰不详），**When** 打开结果页，**Then** 命盘图正常显示其余三柱，并提示「时辰不详，时柱缺失」
6. **Given** 命盘图与四柱明细表，**When** 逐柱比对，**Then** 干支、五行、十神标注与明细表完全一致

---

### User Story 2 - 流通 tab：干支双层箭头 (Priority: P1)

切换到「流通」tab，在相邻柱之间绘制「流通」箭头：天干层（各柱天干之间）与地支层（各柱地支之间）分别连线，按五行相生（绿色「生」）/ 相克（红色「克」）/ 比和（灰色「比」）双标注，让用户直观看到四柱五行之气如何流动、谁生谁克。

**Why this priority**: 流通是命盘图区别于静态表格的核心图示能力，与主图一并构成 MVP；箭头生克关系可完全由现有五行数据推导，不增加用户输入负担。

**Independent Test**: 任取一张盘，比对相邻柱天干/地支的五行，箭头的颜色（生/克/比和）与标准五行生克规则一一对应、与图例一致。可独立验证。

**Acceptance Scenarios**:

1. **Given** 命盘图，**When** 查看相邻两柱，**Then** 天干层与地支层分别存在连接箭头，箭头方向从前者指向后者
2. **Given** 相邻两柱的天干五行，**When** 判定关系，**Then** 相生画绿色箭头并标注「生」（如 木→火）、相克画红色箭头并标注「克」（如 木→土）、五行相同画灰色箭头并标注「比」（比和）
3. **Given** 地支层相邻两柱，**When** 判定关系，**Then** 同样按相生/相克/比和着色并标注（地支五行以本气五行计）
4. **Given** 缺时柱的命盘，**When** 渲染流通箭头，**Then** 年↔月、月↔日箭头正常绘制，涉及时柱的箭头不绘制也不报错
5. **Given** 图例，**When** 对照任一箭头，**Then** 箭头颜色与文字标注均与图例中该五行关系的定义一致
6. **Given** 一条流通箭头，**When** 观察其标注，**Then** 无论颜色如何，箭头上均有「生/克/比」汉字可读

---

### User Story 3 - 宫位 tab：宫位映射表 (Priority: P2)

切换到「宫位」tab，以列表展示四柱的宫位映射与六亲角色：年柱=祖上宫（祖辈/长辈）、月柱=父母宫（父母）、日支=配偶宫（配偶）、时柱=子女宫（子女），让用户一眼看清「每个位置代表谁」。

**Why this priority**: 藏干十神是六亲信息的重要来源，但全量常显会让小屏图过密；折叠方案在不牺牲信息完整性的前提下保持主图清爽。

**Independent Test**: 点击某柱 → 藏干列表展开；再次点击 → 收起；点另一柱 → 前一柱收起、新柱展开。可独立验证。

**Acceptance Scenarios**:

1. **Given** 命盘图，**When** 用户点击某柱的地支区域，**Then** 该柱展开显示藏干列表（每个藏干带五行色与其十神）
2. **Given** 已展开的某柱，**When** 用户再次点击或点击另一柱，**Then** 该柱收起，图面恢复初始状态（同一时刻至多一柱展开）
3. **Given** 无藏干数据的地支，**When** 用户点击，**Then** 不出现空列表，仅提示无可展开明细

---

### User Story 4 - 六亲 tab：十神→六亲 + 图例 (Priority: P2)

切换到「六亲」tab，先展示本命各柱天干十神对应的六亲（如年柱比肩→兄弟姐妹、日主→本人），再附带一张「十神 ↔ 六亲」对照图例：印=父母（偏印亦主母）、官杀=丈夫（女命）/ 上级、财=妻（男命）/ 父亲、比劫=兄弟姐妹、食伤=子女，并注明因性别而异的映射（如男命正官主女儿、女命正财主父亲），帮助用户把柱内十神对应到现实中的人。

**Why this priority**: 六亲是用户诉求之一，但 十神→六亲 映射存在性别差异，需要图例说明，避免误读；作为辅助信息，优先级低于主图与流通。

**Independent Test**: 任取一张盘，按图例逐项比对各柱十神，能正确对应到父母/配偶/子女/兄弟姐妹等六亲角色。可独立验证。

**Acceptance Scenarios**:

1. **Given** 命盘图，**When** 查看底部图例，**Then** 印/官杀/财/比劫/食伤 五组十神均有对应六亲说明
2. **Given** 图例，**When** 查看性别差异条目，**Then** 明确标注「男命」与「女命」不同映射（如正官男命主女儿、女命主丈夫）
3. **Given** 任一柱的十神，**When** 用户对照图例，**Then** 能查得该十神对应的六亲角色

---

### Edge Cases

- **缺时柱**：时辰不详时 `时柱` 为空 —— 主图显示三柱 + 「时辰不详，时柱缺失」提示；涉及时柱的流通箭头不绘制；藏干展开对缺失柱无操作
- **藏干为空/异常**：某地支无藏干数据时，点击不展示空列表，提示无可展开明细
- **五行缺失**：任一干支五行属性缺失时，该字符按中性灰处理，且不参与生克判定（该段箭头不绘制）
- **比和关系**：相邻两柱五行相同（如 午火–巳火）时画灰色比和箭头，不判定为生或克
- **小屏适配**：四柱横向排列在窄屏超宽时，图示等比缩放或允许横向滚动，保证四个柱均可见、不重叠
- **无盘直接访问**：结果页未拿到排盘数据时不渲染命盘图，不抛错
- **数据一致性**：图示任何标注不得与四柱明细表冲突；若明细缺失，图示同步缺失并提示
- **色盲可读性**：流通箭头不可仅依赖红/绿颜色，必须带「生/克/比」汉字标注，红绿色盲用户也能区分相生/相克/比和

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 排盘结果页新增「命盘图」卡片，以**四个 tab**（关系/流通/宫位/六亲）呈现，默认选中「关系」tab，切换 tab 展示不同的信息
- **FR-002**: 「关系」tab 以**八字行 + 上下两层连线**呈现（中间一排八字不变，上方画天干关系、下方画地支关系），纳入当前选中的大运/流年，仅**天干对天干、地支对地支**（不含藏干、不跨层）：天干五合/四冲/相生/相克、地支六合/六冲/相刑（含自刑）/六破/六害，支持三合/三会成局；干支按五行着色
- **FR-003**: 「宫位」tab 必须展示四柱宫位映射（年柱=祖上宫、月柱=父母宫、日支=配偶宫、时柱=子女宫）及对应六亲角色（祖辈/长辈、父母、配偶、子女）
- **FR-004**: 「关系」tab 节点按五行着色并高亮日主；「六亲」tab 须以日主为基准展示各柱天干十神及其对应六亲（日主→本人）
- **FR-012**: 「关系」tab 的连线图必须同时以颜色与文字标注关系类型（合/冲/刑/破/害/克/三合/三会），相邻与跨柱均连，藏干合冲按天干相冲（甲庚/乙辛/丙壬/丁癸）与五合判定
- **FR-013**: 「关系」tab 顶部必须提供**多选**关系类型筛选（合/冲/刑/破/害/克/生/三合/三会），默认不勾选任何类型、不画连线；勾选某类才显示该类连线，可多选组合；下方须固定罗列当前命盘存在的关系汇总（按类型去重），不受筛选影响
- **FR-005**: 「流通」tab 必须在相邻柱之间绘制「流通」箭头：天干层与地支层分开，各自连接年↔月、月↔日、日↔时
- **FR-006**: 流通箭头必须同时以颜色与文字标注五行关系：相生=绿色箭头+「生」、相克=红色箭头+「克」、比和=灰色箭头+「比」；关系按标准五行生克规则（木→火→土→金→水→木 相生；木→土→水→火→金→木 相克）判定
- **FR-007**: 「干支」tab 的地支藏干及藏干十神须直接显示，不折叠、不需点击展开
- **FR-008**: 「六亲」tab 必须提供「十神 ↔ 六亲」对照图例，覆盖 印/官杀/财/比劫/食伤 五组，并标注男命/女命的性别差异映射
- **FR-009**: 时辰不详（缺时柱）时，各 tab 须正常显示其余三柱并提示缺失，流通 tab 不渲染涉及时柱的箭头
- **FR-010**: 命盘图的所有数据必须复用当前排盘结果（干支、五行、十神），不要求用户重复输入，不产生额外排盘计算
- **FR-011**: 图示与四柱明细表的干支/五行/十神标注必须一致；任一数据缺失时图示同步缺省并给出提示

### Key Entities *(include if feature involves data)*

- **四柱（Pillar）**：年/月/日/时四个柱节点，每柱包含干支、干五行、支五行、以日主为基准的天干十神；日柱的日干即日主
- **宫位（Palace）**：四柱各自的六亲宫位——年=祖上宫、月=父母宫、日支=配偶宫、时=子女宫
- **十神（Ten God）**：以日主为基准的十神称谓，是「六亲」的抽象表达；经图例映射为现实亲眷（父母/配偶/子女/兄弟姐妹等）
- **五行流通关系（Flow Relation）**：相邻柱天干之间、地支之间按五行判定的相生/相克/比和关系，驱动箭头方向与颜色
- **地支藏干（Hidden Stems）**：每柱地支所含的藏干及其十神，默认折叠展示

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户打开任意排盘结果页，命盘图在页面加载完成时即完整呈现，无需任何额外点击或操作
- **SC-002**: 命盘图中的干支、五行、十神标注与同页四柱明细表 100% 一致，不存在任何冲突
- **SC-003**: 流通箭头颜色与图例定义 100% 一致，不存在无法解释的箭头
- **SC-004**: 缺时柱（时辰不详）的命盘也能完整渲染，不出现空白、报错或遮挡
- **SC-005**: 藏干明细可在 2 次点击以内完成展开或收起
- **SC-006**: 用户无需外部资料，仅凭图例即可将任一柱的十神对应到父母/配偶/子女/兄弟姐妹等六亲角色
- **SC-007**: 在主流移动端宽度（≥360px）下四个柱节点均可见，不重叠、不溢出
- **SC-008**: 流通箭头均带「生/克/比」文字标注，在模拟红绿色觉缺失的视图中仍能正确识别每条箭头的五行关系

## Assumptions

- 宫位采用通用固定映射：年柱=祖上宫、月柱=父母宫、日支=配偶宫、时柱=子女宫；月柱同时兼主兄弟信息，本期只在图例/备注说明，不在柱内分拆
- 六亲采用通用简化映射：印=父母（偏印亦主母）、官杀=丈夫（女命）/ 上级、财=妻（男命）/ 父亲、比劫=兄弟姐妹、食伤=子女；因性别而异的映射（如男命正官主女儿、女命正财主父亲）通过图例备注说明，不在柱内逐人标注
- 流通箭头仅连接相邻柱（年↔月、月↔日、日↔时），不做跨柱或天干↔地支内部连线；地支五行以本气五行计
- 藏干默认折叠，点击展开；同一时刻至多展开一柱
- 五行标准色沿用项目既有约定（木/火/土/金/水 各色），不引入新配色体系
- 流通箭头文字标注为单一汉字（生/克/比），与颜色并存，不采用图标或符号
- 本功能为纯前端可视化，复用现有排盘结果中的干支、五行、十神数据，无后端接口或数据模型改动
- 端上以移动端为主，图示需在 ≥360px 宽度下可读，必要时等比缩放或横向滚动
