# Feature Specification: 四柱精髓旺度法强弱喜忌分步分析 + 刑冲合害条件入命盘图

**Feature Branch**: `008-yongshen-steps`  
**Created**: 2026-08-16  
**Status**: Draft  
**Input**: User description: "之前的强弱喜忌分析不太准确，现在需要更换一套方法来判定，这里有一篇比较全面的强弱喜忌分析的文章，把文章内容整理总结成计算步骤，一步一步的展示给用户，完后给出最后的喜忌和用神。文章中有刑冲合害的条件，把这些条件应用到命盘图模块里；"

**依据文献**: `doc/四柱精髓（许心友）.doc` —— 许心友《四柱精髓》。核心理论：以"旺相休囚死"取代生旺死绝表衡量五行旺衰；五行旺度量化（度数+系数），先算静态旺度、再经"刑冲合害"与"生克规则"动态修正得最终旺度；由日主旺度辨正格/从格（含化格），正格与从格取用相反；刑冲合害有严格的成立条件与先后论处顺序（相邻方论、合化条件、争合、合绊、先论天合地合、合冲并见规则、六害力量最小最后论等）。

**替换对象**: 005 期（`005-wuxing-strength-scoring`）基于《静态原命局五行力量评分》（李洪成 544 分评分法）的强弱评分与喜忌联动，因用户反馈判定不准确，本期整体替换为《四柱精髓》旺度法。

## Clarifications

### Session 2026-08-16

- Q: 强弱喜忌的计算范围是否包含大运/流年介入后的旺度变化？ → A: **原局+当前大运**——计算步骤中额外展示当前选中大运介入后的旺度变化（按文章大运旺度理论），但最终喜神/用神/忌神结论仍以原局为准；切换当前大运时该步骤随之更新，结论不变
- Q: 最终结论中"用神"如何输出？ → A: **双用神并列**——格局用神（扶抑/从势）与调候用神都作为正式结论并列输出，用户看到两个用神及其各自依据
- Q: 旧 544 分评分法（005 期）的代码与界面如何处置？ → A: **下线但保留代码**——旧评分不再被任何界面调用、不再作为判定依据，但实现代码保留在仓库中不删除，便于回滚对照
- Q: 计算步骤在页面上如何展示？ → A: **结论先行、点击展开**——默认只显示喜忌结论（喜神/忌神/格局用神/调候用神），点击"查看计算过程"后展开全部分步卡片；步骤顺序与内容不变
- Q: 展开的步骤中旺度数值展示到什么程度？ → A: **完整数值轨迹**——每步展示各五行/干支的度数与修正运算过程（如"巳火 3 度 − 合去 1 度 = 2 度"），逐步完全可追溯
- Q: 命盘图中判定后不成立的关系如何呈现？ → A: **汇总单列分组**——图上不画线；关系汇总区单独分组列出未成立/被让位的关系及原因（如"隔位不论""被合绊让位""合而不化"），与成立关系分组分开

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 《四柱精髓》旺度法强弱与格局判定引擎 (Priority: P1)

用户排盘后，系统不再使用旧的 544 分评分法，而是按《四柱精髓》的五行旺度理论计算：先为金木水火土各五行计算静态旺度（依据月令旺相休囚死、干支数量与通根等文章中规定的度量规则），再按天干生克合（五合的合化条件、争合、合绊）与地支刑冲合害（六合、三合/三会/半合、六冲、三刑/自刑、六害）的成立条件与论处先后顺序对旺度做动态修正，得出各五行最终旺度；最后由日主最终旺度判定旺衰级别与格局（正格 / 从强 / 从弱 / 化格等特殊格局）。同一命盘每次计算结果一致、可复现。

**Why this priority**: 这是用户"更换一套方法来判定"的核心诉求——判定引擎的正确性直接决定喜忌结论的可信度，是其余两个故事的数据基础。

**Independent Test**: 以后端单元测试验证：选取文章中的分析命例（书中带完整推演过程的实例），逐例对照中间旺度与最终格局判定与文章结论一致；同一命盘两次计算完全一致；无需前端即可验证。

**Acceptance Scenarios**:

1. **Given** 任意已排出的命盘，**When** 系统计算强弱，**Then** 先产出各五行的静态旺度，再依次经天干生克合、地支刑冲合害动态修正，产出各五行的最终旺度
2. **Given** 一组存在天干五合的命盘，**When** 判定该合，**Then** 按文章条件区分"合化成功"与"合而不化（合绊）"，两种结果对旺度的修正不同，且出现争合时按文章争合规则处理（力量大/满足条件多者优先，势均力敌双方不论合化）
3. **Given** 一组地支多种关系并见的命盘（如同时有六合、六冲、三刑、六害），**When** 判定论处顺序，**Then** 按文章先后顺序规则处理（如天合地合优先于天克地冲、合冲并见按文章规则、六害力量最小最后论）
4. **Given** 两支不相邻且无文章规定的特例关系，**When** 判定其作用，**Then** 不论刑冲合害（相邻才论，隔位不论，文章特例除外）
5. **Given** 日主最终旺度，**When** 判定格局，**Then** 按文章标准区分正格（身旺/身弱）与特殊格局（从强、从弱、化格），旺极/无根无生扶等边界情形按文章处理
6. **Given** 文章中带完整推演结论的命例，**When** 用新引擎计算，**Then** 中间旺度与最终格局/喜忌结论与文章一致
7. **Given** 同一组出生信息，**When** 两次排盘计算，**Then** 静态旺度、动态修正过程、最终旺度、格局判定完全一致

### User Story 2 - 计算步骤分步展示 + 最终喜忌与用神 (Priority: P1)

用户在喜忌分析区域先看到最终结论（喜神、忌神、格局用神、调候用神），点击"查看计算过程"后展开按《四柱精髓》方法整理总结的完整计算步骤：从排定四柱与月令、静态旺度、天干生克合修正、地支刑冲合害修正、最终旺度、当前大运介入后的旺度变化、旺衰与格局判定，到取用神，**一步一步展示**——每一步展示该步的名称、依据的规则、参与计算的干支/五行与中间结果，用户可以逐步查看推演过程；格局用神与调候用神并列输出、各附依据。

**Why this priority**: "一步一步展示给用户，完后给出最后的喜忌和用神"是用户的原话诉求——可解释的推演过程是用户信任新判定方法的关键，与引擎同为本期核心交付。

**Independent Test**: 排出一张盘，逐步核对页面上每一步的中间结果与后端引擎输出一致、步骤顺序完整、末步喜神/用神/忌神与格局判定方向自洽（如身旺正格喜克泄耗、忌生扶）。

**Acceptance Scenarios**:

1. **Given** 一张已排出的命盘，**When** 查看喜忌分析，**Then** 默认只显示结论（喜神、忌神、格局用神、调候用神）；点击"查看计算过程"后展开按顺序排列的计算步骤列表，每步含步骤名、规则说明与该步的中间结果
2. **Given** 步骤列表，**When** 查看动态修正相关步骤，**Then** 能看到哪些刑冲合害/生克关系参与了修正、各自的判定结果（成立/不成立、合化/合绊/冲/刑/害）及对旺度的影响
3. **Given** 完整步骤推演结束，**When** 查看末步，**Then** 明确给出喜神、忌神与并列的两个用神——格局用神与调候用神（各附依据），且格局用神与所判格局方向自洽（正格扶抑、从格从势）
4. **Given** 一张从格命盘，**When** 查看结论，**Then** 用神取所从之势（与正格取法相反），并在步骤中体现从格判定的依据
5. **Given** 页面展示的每一步，**When** 与引擎输出比对，**Then** 中间数值与判定结果一致，无前后矛盾
6. **Given** 旧的 544 分评分展示，**When** 查看喜忌分析区域，**Then** 旧评分口径不再作为强弱与喜忌的判定依据出现
7. **Given** 一张已排出且选中了当前大运的命盘，**When** 查看计算步骤，**Then** 原局最终旺度之后有一步展示该大运介入后的旺度变化（按文章大运旺度理论），且喜神/用神/忌神结论仍与原局判定一致
8. **Given** 步骤展示中的大运介入步，**When** 用户切换当前选中的大运，**Then** 该步的旺度变化随之更新，而喜忌结论保持不变

### User Story 3 - 刑冲合害成立条件应用到命盘图关系判定 (Priority: P2)

命盘图（007 期"关系"tab）的干支关系判定改用《四柱精髓》的刑冲合害条件：只有相邻的干支才论生克合与刑冲合害（隔位不论，文章特例除外）；天干五合区分合化成功与合绊；争合按争合规则取舍；地支六合/三合/三会/六冲/三刑/自刑/六害按文章条件判定是否成立；多组关系并见时按文章的论处先后顺序决定哪些关系成立（如天合地合优先、合冲并见规则、六害最后论）。连线与"当前命盘存在的关系汇总"均以判定后的结果为准：不成立的关系不画线，但在汇总区单独分组列出（附未成立原因，如"隔位不论""被合绊让位""合而不化"），与成立关系分组分开；成立的关系标注其结果状态（如"合化火""合绊""冲""刑"）。当前选中的大运/流年与命局干支之间的作用同样按此条件判定。

**Why this priority**: 命盘图现有的关系连线是"见合画合、见冲画冲"的静态枚举，不含成立条件；把文章条件应用进来后，图上关系与强弱喜忌分析使用同一套判定口径，避免"图上说午未合化火、分析里却按合绊"这类自相矛盾。优先级低于判定引擎与分步展示（引擎产出的判定结果可直接复用于图）。

**Independent Test**: 构造含争合、合冲并见、隔位相合的命盘各一例，核对图上连线与汇总：隔位关系不出现、被优先关系"让位"的关系不出现、成立的关系标注状态正确，且与喜忌分析步骤中的判定结果完全一致。

**Acceptance Scenarios**:

1. **Given** 一张两支相合但不相邻（且无文章特例）的命盘，**When** 查看命盘图关系 tab，**Then** 该合不画线，但在汇总区的"未成立"分组中列出并标注原因"隔位不论"
2. **Given** 一组天干五合满足文章合化条件，**When** 查看关系图，**Then** 该关系标注为合化及所化五行；不满足合化条件时标注为合绊
3. **Given** 一张合冲并见的命盘，**When** 系统按文章先后顺序判定，**Then** 图上只绘制判定成立的关系，被让位/解除的关系不绘制，且判定结果与喜忌分析步骤中的记录一致
4. **Given** 一张存在争合的命盘，**When** 查看关系图，**Then** 按争合规则只显示优先成立的一组（或势均力敌时按文章均不论合化处理）
5. **Given** 选中某个大运/流年，**When** 其干支与命局干支存在刑冲合害，**Then** 按同一套成立条件与先后顺叙判定后再画线/汇总
6. **Given** 关系类型筛选（007 已有多选筛选），**When** 勾选某类关系，**Then** 只显示该类中按本期条件判定成立的关系

### Edge Cases

- 缺时柱（时辰不详）的命盘：旺度计算与步骤展示在缺柱情况下正常进行，并明确提示时柱缺失对判定的影响；命盘图涉及时柱的关系不绘制。
- 某五行在原局完全缺失（0 个）：旺度为零时修正与取用神按文章规则处理，步骤中如实展示。
- 合化成功改变了参与干支的五行属性后，后续关系的判定以文章规定的口径为准（化后参与 vs 原五行参与）。
- 自刑、三刑缺一、半合/拱合等边缘组合：严格按文章给出的成立条件判定，条件不足按不成立处理并在步骤中说明。
- 日主旺度恰好落在正格与从格的临界：按文章给出的判别标准（如有根无根、有无生扶）裁定，步骤中展示裁定依据。
- 大运/流年与命局之间出现多组关系并见：与原局并见使用同一先后顺序规则。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 用《四柱精髓》五行旺度理论替换现有 544 分评分法，作为强弱与喜忌判定的唯一口径；旧评分不再被任何界面调用、不再参与喜忌结论，但其实现代码保留在仓库中（下线不删除，便于回滚对照）。
- **FR-002**: 系统 MUST 先计算各五行的静态旺度：以月令旺相休囚死为基础，按文章规定的度量规则（干支度数、通根、系数等）量化金木水火土各自的旺度。
- **FR-003**: 系统 MUST 在静态旺度基础上按天干关系做动态修正：天干相生相克的增减力规则、天干五合的合化条件（区分合化成功与合绊）、争合规则（力量大/条件多者优先，势均力敌均不论合化）。
- **FR-004**: 系统 MUST 按地支刑冲合害做动态修正：六合、三合/三会/半合、六冲、三刑（含自刑）、六害的成立条件，以及"合化成功/合而不化"对旺度的不同修正。
- **FR-005**: 系统 MUST 遵循文章的论处先后顺序：相邻才论（隔位不论，文章特例除外）、天合地合优先于天克地冲、合冲并见按文章规则裁定、刑冲合的力量优先于六害（六害最后论）等。
- **FR-006**: 系统 MUST 由最终旺度判定日主旺衰级别与格局：正格（身旺/身弱等分级）与特殊格局（从强、从弱、化格），临界情形按文章判别标准裁定。
- **FR-007**: 系统 MUST 按格局取用神并给出喜忌：正格按扶抑取用（旺抑弱扶），从格按所从之势取用（与正格相反）；同时按文章调候理论取调候用神。最终结论 MUST 双用神并列输出：**格局用神**与**调候用神**均为正式结论（附各自依据），并给出喜神、忌神。
- **FR-008**: 系统 MUST 将上述计算整理为有序步骤向用户分步展示：每步含步骤名、规则说明、参与干支/五行、**完整数值轨迹**（各五行/干支的度数与修正运算过程，如"巳火 3 度 − 合去 1 度 = 2 度"）；原局最终旺度之后 MUST 包含"当前选中大运介入后的旺度变化"步骤（按文章大运旺度理论），切换当前大运时该步随之更新；末步给出喜神/忌神与并列的格局用神、调候用神结论，且结论始终以原局为准、不随大运切换改变。展示形态为结论先行：默认只显示结论，点击"查看计算过程"后展开全部步骤。
- **FR-009**: 步骤展示的内容 MUST 与引擎实际计算一致、逐步可追溯；结论与格局判定方向自洽。
- **FR-010**: 命盘图"关系"tab 的关系判定 MUST 改用文章的刑冲合害条件：不成立的关系不画线，但 MUST 在汇总区单独分组列出并附未成立原因（与成立关系分组分开）；成立的关系标注其结果状态（合化及所化五行/合绊/冲/刑/害等）。
- **FR-011**: 命盘图 MUST 应用文章的论处先后顺序：多关系并见时只绘制裁定成立的关系，且与喜忌分析步骤中的判定记录一致。
- **FR-012**: 命盘图中当前选中的大运/流年与命局干支之间的作用 MUST 按同一套成立条件与先后顺序判定。
- **FR-013**: 同一命盘的计算 MUST 可复现：静态旺度、修正过程、最终旺度、格局、喜忌结论每次一致。
- **FR-014**: 系统 MUST 对缺时柱命盘正常完成计算与展示，并提示时柱缺失的影响。

### Key Entities

- **五行旺度**: 某一行（金/木/水/火/土）在命局中的量化强度；分静态旺度（月令旺相休囚死+干支度量）与最终旺度（经刑冲合害/生克动态修正后）。
- **干支关系判定**: 一对（或一组）天干/地支之间的关系及其裁定结果——类型（五合/六合/三合/三会/六冲/三刑/自刑/六害/生/克）、成立与否、结果状态（合化所化五行 / 合绊 / 冲破等）、论处顺序；原局内部及大运流年与命局之间均适用。
- **格局判定**: 由日主最终旺度得出的命局类型（正格分级 / 从强 / 从弱 / 化格）及裁定依据。
- **喜忌结论**: 由格局推导的喜神、忌神，以及并列输出的格局用神与调候用神（各附依据）。
- **计算步骤**: 一次强弱喜忌推演的有序步骤序列，每步含名称、规则、参与要素与完整数值轨迹（度数与修正运算过程），末步为喜忌结论。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 从文章中选取不少于 5 个带完整推演结论的命例，新引擎的格局与喜忌结论与文章一致率达到 100%。
- **SC-002**: 同一命盘任意次重复计算，静态旺度、最终旺度、格局、喜忌结论完全一致（可复现率 100%）。
- **SC-003**: 用户查看任意命盘的喜忌分析时，能看到完整的步骤链（从静态旺度到喜忌结论），每步中间结果可追溯，无跳步。
