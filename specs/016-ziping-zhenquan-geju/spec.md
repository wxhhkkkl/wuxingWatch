# 016 子平真诠格局判定引擎

## 目标

- 以**《子平真诠》（沈孝瞻）**为唯一规则源，输出图上 **25 类主格**：
  - 正八格：正官、七杀、正财、偏财、正印、偏印、食神、伤官
  - 禄刃格：建禄、阳刃
  - 专旺格：曲直、炎上、稼穑、从革、润下
  - 从格：从财、从杀、从儿、从势、从气
  - 化格：化土、化金、化水、化木、化火
- 替换 015 期的 49 格引擎（API/前端已切换）；015 模块保留为历史/对照，不再被 API 调用。
- 本期**只判格名**；成破、用神/相神、喜忌、流年不在范围。

## 规则源

- 文本库 `books.id=32`《子平真诠》，51 章（含徐乐吾评注）。
- 书证按 `chapter` + `chapters.id` + 原文引用，不标页码。
- 关键篇：论用神、论用神变化、论杂气如何取用、论正官、论财、论印绶、论食神、论偏官、论伤官、论阳刃、论建禄月劫、论杂格。

## 已确认口径（2026-11-18）

1. **G1 月令为纲**；杂气/本气不透时，月令藏干透出或月支会支可改格。
2. **G2 非月令透干不改格**；只作相神/救应。
3. **G3 阳刃**：甲卯、丙戊午、庚酉、壬子为阳刃；其余月令比劫为建禄/月劫。
4. **G4 从杀**须四柱皆煞、日主无根；有比劫根/透判七杀。
5. **G5 食神**按月令；非月令伤官不改食神格。
6. **G6 官煞混杂取清**；月令官透则官格（014 丁壬合、亥寅六合仍取正官）。
7. **G7 正偏**按十神极性拆分，不照抄 note。
8. **G8** 098 按老师/引擎判伤官；从儿/从势/从气 3 类书无独立章节，输出「未定」。

老师 2026-11-18 逐例确认 32 例差异：28 例按文本、4 例按老师（014 正官、017 食神、019 食神、096 食神）。确认记录见 `fixtures/teacher-confirmation.json`。

## 输出与 API

- 引擎：`backend/src/services/bazi/zhenquan/`，入口 `judge_yuanju(pillars, wan_du)`。
- 输出：`main_ge.name`（25 类或未定）、`group`、`reason`、`citation`、`flags`。
- API：`/api/charts/geju` 与 `/api/records/{id}/geju` 已切到 `engine="zhenquan-geju"`；适配旧响应字段，成破/用神/喜忌置空，前端显示「016 期未覆盖」。
- 大运步：格名同原局；身强弱取该步引擎2 旺度；喜忌/成破置空。

## 非目标

- 成破、病药、救应、高低。
- 用神/相神/喜忌。
- 流年/流月/流日/流时。
- 从儿/从势/从气（书无独立章节，输出未定）。
