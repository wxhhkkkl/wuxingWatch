# Feature Specification: 五行力量评分驱动的强弱分析与喜忌联动

**Feature Branch**: `005-wuxing-strength-scoring`  
**Created**: 2026-08-12  
**Status**: Draft  
**Input**: User description: "喜忌分析中 强弱分析按文档 @doc/静态原命局五行力量评分(1).docx 来进行计算分数，完后按分数来定义强弱，点击强弱可以查看详细得强弱计算过程； 再用这个计算出来得强弱来衡量喜神用神忌神"

**依据文档**: `doc/静态原命局五行力量评分(1).docx` —— 李洪成五行力量评分的标准化统一版（544 分基准、109 分中和线、月令系数、通根远近、合冲刑会修正、旺衰等级）。本期把其中"约数、活看"的部分标准化为可重复计算的口径。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 强弱分析按文档评分计算 (Priority: P1)

用户排盘后，喜忌分析中的"强弱"不再由简单的干支五行计数判定，而是由一套完整的五行力量评分得出：系统为金、木、水、火、土五个五行分别计算标准化分数（总分恒为 544，中和线 109 分），日主所属五行的分数对照旺衰等级表得出强弱（旺极/太旺/偏旺/中和/偏弱/太弱，及无生扶时的从格）。同一命盘每次计算分数一致，可复现。

**Why this priority**: 这是用户的核心诉求——用文档的专业评分法替换现有简单启发式判断，是后续喜用忌判定的基础，属于本功能的根基。

**Independent Test**: 用后端单元测试验证：坐支修正步与文档内联示例（戊辰/戊午）逐格手算一致、各五行总分恒等于 544、两次计算可复现、强弱等级与分数区间严格对应；无需前端即可验证。

**Acceptance Scenarios**:

1. **Given** 任意已排出的命盘，**When** 系统计算强弱，**Then** 金木水火土五行各得到一个标准化分数，五个分数之和恒等于 544
2. **Given** 日主所属五行的标准化分数，**When** 对照旺衰等级表，**Then** 强弱等级按表判定（>435 旺极 / 272～435 太旺 / 114～272 偏旺 / 104～114 中和 / 45～104 偏弱 / <45 太弱），且日主五行完全无生扶且分数极低时另判从格
3. **Given** 排盘结果页的喜忌分析区域，**When** 查看"强弱"，**Then** 直接显示旺衰等级标签（如"偏旺""太弱"），而非仅"身强/身弱"二值
4. **Given** 同一组出生信息，**When** 两次排盘，**Then** 五行分数与强弱等级完全一致
5. **Given** 一个手算核验过的参考命例（如文档戊辰/戊午示例），**When** 计算对应修正步，**Then** 中间值与按文档逐格手算的结果一致，且各五行总分恒为 544

### User Story 2 - 用强弱衡量喜神用神忌神 (Priority: P1)

喜忌分析的结论由评分得出的强弱驱动：偏旺及以上（身强）的命局喜克泄耗（官杀/食伤/财）、忌生扶（印/比劫）；偏弱/太弱（身弱）的命局喜生扶（印/比劫）、忌克泄耗；**从格（弃命从势）喜克泄耗、忌生扶，用神取克泄耗中分数最高者（所从强神）**；中和的命局用神取全盘分数最低的五行（补缺）、忌神取分数最高的五行（抑强）。身强/身弱时用神从喜用候选中取标准化分数最低的五行，避免"用神恰是命局失衡方"的明显矛盾。

**Why this priority**: "用计算出来的强弱来衡量喜神用神忌神"是用户明确要求的第二步，直接决定喜忌结论的正确性，与故事 1 同为核心交付。

**Independent Test**: 用后端测试构造强盘与弱盘各一例，断言用神/喜神/忌神的选择符合强弱方向（强盘喜克泄耗、弱盘喜生扶），且用神取法符合 FR-012（身强/身弱取候选最低、从格取所从强神、中和补缺抑强）。

**Acceptance Scenarios**:

1. **Given** 一个被判定为偏旺及以上的命盘，**When** 计算喜用忌，**Then** 用神与喜神属于克泄耗五行（克我/我生/我克），忌神属于生扶五行（同我/生我）
2. **Given** 一个被判定为偏弱/太弱的命盘，**When** 计算喜用忌，**Then** 用神与喜神属于生扶五行（印/比劫），忌神属于克泄耗五行
3. **Given** 一个被判定为中和的命盘，**When** 计算喜用忌，**Then** 用神为全盘标准化分数最低的五行，忌神为分数最高的五行，喜神为用神的相生五行
4. **Given** 强盘/弱盘的喜用候选集合，**When** 选出发用神，**Then** 用神为该集合中标准化分数最低的五行
5. **Given** 一个被判定为从格的命盘，**When** 计算喜用忌，**Then** 用神为克泄耗中分数最高的五行（所从强神），忌神属于生扶五行

### User Story 3 - 点击强弱查看详细计算过程 (Priority: P2)

用户排盘后，喜忌分析区域的"强弱"可点击，进入独立的强弱详情页逐行展示该命盘完整的力量评分过程：基础分（四干分、四支藏干分）→ 通根远近修正 → 天干坐支修正 → 天干间生克修正 → 月令系数 → 合冲刑会系数 → 标准化 → 旺衰等级判定 → 从格判断（如适用）。每一步列出涉及五行、数值与说明，用户能看懂分数从何而来。

**Why this priority**: "点击强弱查看详细计算过程"是用户明确提出的交互需求，但依赖故事 1 的评分输出，故优先级次之。

**Independent Test**: 排盘后点击结果页的"强弱"，核验进入独立详情页且展示的每一步与后端评分输出的中间值一一对应；可单独交付（先于故事 2 也不影响故事 1 的价值）。

**Acceptance Scenarios**:

1. **Given** 排盘结果页的喜忌分析区域，**When** 用户点击"强弱"，**Then** 进入独立的强弱详情页（与"时辰详解"同类入口）
2. **Given** 强弱详情页，**When** 展示计算过程，**Then** 按文档流程逐行展示：基础分、通根远近、坐支、天干生克、月令、合冲刑会、标准化、等级判定，并列出各五行关键中间值与最终分
3. **Given** 强弱详情页，**When** 用户返回，**Then** 回到结果页原位置，不影响其他区域
4. **Given** 一条不含评分数据的旧排盘记录，**When** 查看结果页，**Then** 不展示"强弱"点击入口，其余内容正常

---

### Edge Cases

- **四柱输入模式（无公历日期）**：强弱评分只需要四柱干支，MUST 正常计算并展示详情
- **时辰不详（无时柱）**：按年/月/日三柱参与计算，详情中注明"时柱缺失"；不报错
- **某五行无任何透干与根**：该行分数为 0，标准化时其余五行按比例放大，总分仍为 544
- **从格**：日主五行完全无生扶且分数极低 → 判定从格，喜用忌按"弃命从势、喜克泄耗"处理
- **合化成立条件不满足**：按"合而不化"处理（仅按表 7 的六合未化 ×1.05），不套用化神系数
- **旧记录无评分字段**：前端空值兜底，不展示详情入口；建议重新排盘后可见新字段
- **多根相连/根被冲破/盖头根**：按文档的 ×0.95 / ×0.80 / ×0.50～0.70 依次处理，不叠加重复折扣

## Requirements *(mandatory)*

### Functional Requirements

**五行力量评分**

- **FR-001**: 系统 MUST 按文档方法为金木水火土五行计算标准化分数；总分恒等于 544，理论中和线 109 分
- **FR-002**: 天干基础分 MUST 按"同五行透干数量 × 36"计算（四干共 144 分）
- **FR-003**: 地支藏干 MUST 按文档表 0 分值统计（如子癸 100、丑己 60/辛 30/癸 10、寅甲 60/丙 30/戊 10 等），四支各计 100 分（共 400 分）
- **FR-004**: 有效根气 MUST 按"藏干基础分 × 距离系数 × 根气状态系数"计算；距离系数按文档表 1（坐支 1.00 / 邻支 0.90 / 隔支 0.75 / 遥支 0.60）；相连根按 0.95、被冲破根再乘 0.80、被严重盖头根再乘 0.50～0.70（标准化取中值 0.60，见 research R3）
- **FR-005**: 天干坐支修正 MUST 按文档表 2 的五种干支关系修正（干支同五行比和 / 地支生天干 / 天干生地支 / 天干克地支 / 地支克天干），同一柱只能选择一种主要关系，不能重复叠加
- **FR-006**: 天干之间生克 MUST 按文档表 3/表 4 系数修正（同性相克主克 ×0.70 被克 ×0.50、异性相克 ×0.85/×0.70、同性相生主生 ×0.80 被生 ×1.20、异性相生 ×0.70/×1.30），并按距离修正（紧贴 100% / 隔一干 ×0.90 / 遥隔 ×0.80），只计算有明确作用路线的关系，避免重复扣分
- **FR-007**: 月令权重 MUST 按文档表 5/表 6 系数（X 与月令同五行 ×1.50 / 月令生 X ×1.20 / X 生月令 ×0.80 / X 克月令 ×0.70 / 月令克 X ×0.50），作用于"修正天干分 + 有效根气分"之和
- **FR-008**: 合冲刑会 MUST 按文档表 7 倍率修正（三会局 ×1.20 / 三合局 ×1.15 / 半合半会 ×1.08 / 六合未化双方 ×1.05 / 六合合化成功化神 ×1.15 且原五行相关根 ×0.85 / 强根被冲 ×0.80 / 普通刑 ×0.90 / 三刑成立 ×0.85）；合化成立 MUST 同时满足文档条件（得月令或有强根、有化神透干或化神根气充足、无严重冲破、**化神五行最终分高于原五行最终分**——用同一评分体系量化"明显高于"，其中"最终分"以第一遍未标准化的加权分 W_raw 比较以消除循环依赖，见 research R5），否则按"合而不化"（六合未化 ×1.05）处理；同一结构只计算一次
- **FR-009**: 标准化 MUST 按"W五行 ÷ 五行总 W × 544"计算，使总分保持 544、中和线 109 继续可用
- **FR-010**: 强弱等级 MUST 按文档表 8 判定（435 分以上旺极 / 272～435 太旺 / 114～272 偏旺 / 104～114 中和 / 45～104 偏弱 / 45 分以下太弱）；日主五行完全无生扶且属太弱时，另判断是否形成从格
- **FR-011**: 强弱计算 MUST 是可复现的纯函数——相同四柱输入得到相同的五行分数与等级；排盘与保存记录使用同一口径

**喜用忌联动**

- **FR-012**: 喜忌结论 MUST 由 FR-010 的强弱驱动：偏旺及以上（身强）喜克泄耗（克我/我生/我克）、忌生扶（同我/生我），用神取克泄耗中分数最低者；偏弱/太弱（身弱）喜生扶（印/比劫）、忌克泄耗，用神取生扶中分数最低者；**从格（弃命从势）喜克泄耗、忌生扶，用神取克泄耗中分数最高者（所从强神）**；中和（日主五行分 104～114）时用神取全盘标准化分数最低的五行（补缺）、忌神取分数最高的五行（抑强）、喜神取用神的相生五行
- **FR-013**: 身强/身弱时，用神 MUST 从喜用候选中取标准化分数最低的五行（以评分为据，而非简单五行计数）；从格与中和的用神规则见 FR-012（从格取克泄耗最高分、中和取全盘最低）
- **FR-014**: 既有喜忌输出结构（conclusion / favorable_elements / avoid_elements / reasoning / ten_gods / direction / disclaimer）MUST 保持兼容；本功能以**增量**方式新增强弱字段，不破坏既有字段

**强弱展示与详情**

- **FR-015**: 结果页喜忌分析中的"强弱" MUST 直接展示文档 7 级旺衰等级标签（旺极/太旺/偏旺/中和/偏弱/太弱/从格），而非仅"身强/身弱"二值；喜忌逻辑内部按身强/身弱/中和/从格四类分类
- **FR-015a**: "强弱" MUST 可点击，点击后进入独立的强弱详情页（与"时辰详解"同类入口），逐行展示该命盘的完整评分过程（基础分 / 通根 / 坐支 / 天干生克 / 月令 / 合冲刑会 / 标准化 / 等级判定 / 从格判断），每一步 MUST 与后端评分输出的中间值一一对应，并列出各五行关键数值；返回后回到结果页原位置
- **FR-016**: 不包含评分数据的旧记录 MUST 不展示"强弱"点击入口，页面其余功能不受影响

**既有功能保持**

- **FR-017**: 既有出生信息、四柱明细、大运流年联动、人元司令/宫位、保存记录、生成长图等功能 MUST 保持可用且内容不变

### Key Entities

- **五行评分 (Element Score)**: 某一五行（金/木/水/火/土）的评分明细——天干基础分、有效根气分、坐支/生克修正、月令系数、合冲刑会结构系数、标准化后的最终分数
- **强弱判定 (Strength Verdict)**: 日主所属五行的标准化分数、等级（旺极/太旺/偏旺/中和/偏弱/太弱/从格）、判定依据；驱动喜用忌
- **评分步骤 (Score Step)**: 计算过程中的每一步——步骤名称、涉及五行、数值、说明文字；用于详情视图逐行展示
- **喜忌结论 (Xiyong Conclusion)**: 用神/喜神/忌神及方向解读，由强弱判定驱动（复用既有结构）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 任意命盘的五行标准化分数总和恒等于 544，且相同输入两次计算分数与等级完全一致（复现率 100%）
- **SC-002**: 坐支修正步与文档内联示例（戊辰 66 分、戊午 46.8/49 分）逐格手算一致；自构造至少 3 个命例验证守恒性（总分恒 544）、可复现性与等级区间映射全部成立；既有 1987-05-31 参考盘的强弱等级判定合理
- **SC-003**: 强弱判定从既有的"身强/身弱"二值升级为文档 7 级口径（旺极/太旺/偏旺/中和/偏弱/太弱/从格），且与标准化分数区间严格一一对应
- **SC-004**: 喜用忌方向与强弱判定一致率 100%——凡强盘必喜克泄耗、凡弱盘（偏弱/太弱）必喜生扶、凡从格必喜克泄耗且用神取克泄耗中分数最高者
- **SC-005**: 用户点击"强弱"后在 1 秒内看到详情，且详情展示的每一步中间值均可与后端评分输出逐条对应
- **SC-006**: 新强弱评分数据使排盘结果数据量增量小于 30KB（含评分明细），结果页首屏加载速度不受影响

## Assumptions

- 以文档《静态原命局五行力量评分(1).docx》为唯一算法依据，采用其"统一版"的可重复计算口径（把"约数、活看"标准化为固定规则）
- 合冲刑会采用文档表 7 的倍率体系（不使用"固定加 40/80 分"法）；合化成立条件按文档四条同时满足，其中"化神力量明显高于原五行"量化为"化神五行最终分高于原五行最终分"
- 五行评分与强弱判定作为可独立测试的领域逻辑实现（符合项目宪法：排盘核心逻辑可独立测试），用户界面只负责渲染评分详情
- 用神选取采用"喜用候选分数最低者"（以评分为据）；方向解读（事业/财运/健康）保持既有逻辑，仅强弱来源改变
- 旧 `chart_result` 记录不迁移：新强弱字段缺失时前端空值兜底
- 强弱直接展示文档 7 级旺衰等级标签（旺极/太旺/偏旺/中和/偏弱/太弱/从格）；喜忌逻辑内部按身强/身弱分类
- 强弱详情以独立详情页呈现（与"时辰详解"同类入口），不采用弹窗或页内折叠
- 本期**不做**文档中未提及的内容（如大运/流年维度的力量评分、小运、从格的极端细分）——强弱评分仅用于原命局静态分析
