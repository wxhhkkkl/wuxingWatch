**Feature Branch**: `009-wangdu-optimization`  
**Created**: 2026-08-19  
**Status**: Draft  
**Input**: User description: "计算旺度得顺序要调整一下成以下：阶段一：静态旺度（只动地支，不动天干之间的生克、天干五合）……阶段二：动态旺度（开始天干之间作用）：动态 A 紧贴天干之间作用（年干-月干、月干-日干、日干-时干）优先判天干五合再判普通生克；动态 B（许心友原著独有；甲木版本删掉）遍历四柱，同柱天干 ↔ 本柱全部藏干配对运算"

**变更对象**: 008 期（`008-yongshen-steps`）已实现的《四柱精髓》旺度引擎——本期**只调整计算顺序与阶段划分**，不新增/删除旺度理论规则本身；格局判定、取用神、调候、大运介入的既有口径沿用 008 期。

## 背景与设计原则

《四柱精髓》（许心友）旺度计算的顺序重排，核心原则两条：

1. **静态＝地支结构**：静态旺度阶段只考虑"地支那一套"（藏干 + 刑冲合害 + 通根 + 月令秉气），**不考虑生克规则**；此时天干尚未发生互相作用，天干保持原始 1 度状态、天干五合完全不处理。
2. **天干五合归动态**：天干五合属于天干之间的"生克作用体系"，只能在阶段二（天干开始互作用后）判定，绝不在静态阶段处理。

## 算法阶段说明

### 阶段一 静态旺度（只动地支，不动天干）

1. **原始藏干列出**：按藏干度数表列出四柱各支的原始藏干与度数（008 既定：本气/半本气/中气/余气/纯本气，四墓库随月令变表）。
2. **处理地支关系**（仅修改地支藏干度数）：
   - 论处先后（高→低，按《四柱精髓》原文，2026-08-19 Q3）：**辰戌丑未土局 ＞ 丑未戌三刑 ＞ 三支自刑（三辰自刑除外）＞ 会局（三会）＞ 三合局 ＞ 生地半三合 ＞ 六冲 ＞ 六合 ＞ 墓地半三合（巳酉合等同墓地半三合）＞ 子卯刑/寅巳申刑/两支自刑/丑未戌两支相刑 ＞ 六害**；破不在书中体系、保留排最后。天合地合/天克地冲为干支并见项，按两阶段拆分：地支部分归本阶段、天干部分归动态阶段。
   - 只改地支藏干度数；**天干五合这里完全不处理**，天干保持原始状态。
   - 静态只管地支结构；天干在阶段一不发生任何互相作用。
3. **通根运算**（连片、距离衰减、月令特权）——作用于地支关系处理后的藏干度数。
4. **× 月令秉气系数**，得到**静态旺度**（各个天干、藏干的静态分数）。

### 阶段二 动态旺度（开始天干之间作用）

- **动态 A：紧贴天干之间作用**（仅年干‑月干、月干‑日干、日干‑时干三对）。
  - 该步内部**优先判定天干五合**，再算普通天干相生相克（原文规则：**合优先于普通生克**）。
  - 先看紧贴天干有没有天干五合：
    - **合而不化（合绊）**：不改变五行，只修改两个天干旺度；**贪合忘生克**——这一对不再执行普通相生相克倍率。
    - **合化成功**：满足月令、化神条件，两个天干废弃原五行，替换成化神五行的旺度。
    - **争合、妒合**同样在动态 A 第一步判断。
  - 如果该对没有五合，再执行普通天干相生、相克（判生克权，套倍率公式）。
- **动态 B（许心友原著独有；甲木版本删掉）**：遍历四柱，**同柱天干 ↔ 本柱全部藏干**配对运算（全部藏干逐个套用 008 同柱生克系数公式：同性/异性生克权重 + 生克权 ≥2.4，2026-08-19 Q4）。

### 动态阶段之后（沿用 008 期口径）

- 动态阶段产出修正后的天干旺度，与阶段一修正后的地支藏干度数合并，得到各五行**最终旺度**与日主旺衰等级。
- 后续**格局判定**（正格/从强/从弱/从印/从杀/从财/化格）、**取用神与喜忌**（格局用神 + 调候用神双并列）、**大运介入修正**（仅展示不改变结论）沿用 008 期规则不变。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 阶段一：静态旺度（只动地支结构） (Priority: P1)

系统先进入静态阶段：列出四柱各支原始藏干度数，按《四柱精髓》论处先后（辰戌丑未土局＞丑未戌三刑＞三支自刑＞会局＞三合局＞生地半三合＞六冲＞六合＞墓地半三合＞子卯/寅巳申/两支自刑/丑未戌两支相刑＞六害）处理地支关系、只修改地支藏干度数；随后做通根运算（连片、距离衰减、月令特权），再乘月令秉气系数，产出各天干、各藏干的静态分数。**整个静态阶段不处理天干五合、不执行任何天干之间的生克**——天干保持原始 1 度状态。

**Why this priority**: 静态阶段是用户指定的第一步，也是后续动态修正的地基；"天干五合不在静态做"是本期内核原则，直接决定计算顺序正确性。

**Independent Test**: 后端单元测试构造"同一天干五合组合、仅改变顺序"的命盘，验证静态阶段输出完全不受天干五合影响；取书中有完整推演的地支结构命例，逐例对照藏干修正后的静态分数。

**Acceptance Scenarios**:

1. **Given** 任意已排出命盘，**When** 计算静态旺度，**Then** 输出按序为：原始藏干列表 → 地支关系处理（含各关系判定与藏干度数变化轨迹）→ 通根运算 → 乘月令系数后的各天干/藏干静态分数
2. **Given** 一张天干存在五合的命盘，**When** 进入静态阶段，**Then** 该五合对任何静态分数**零影响**，天干维持原始 1 度，步骤中无任何五合处理记录
3. **Given** 一张地支多关系并见的命盘，**When** 静态阶段处理地支，**Then** 严格按《四柱精髓》论处先后（辰戌丑未土局＞丑未戌三刑＞三支自刑＞会局＞三合局＞生地半三合＞六冲＞六合＞墓地半三合＞子卯/寅巳申/两支自刑/丑未戌两支相刑＞六害）裁定，低优先级关系被高优先级让位时如实记录原因
4. **Given** 地支关系处理完成后的藏干度数，**When** 做通根运算，**Then** 连片不减/距离衰减/月令特权规则（008 C11）对修正后藏干生效
5. **Given** 静态藏干分数，**When** 乘月令秉气系数，**Then** 各天干、各藏干得到与月令状态对应的静态分数

### User Story 2 - 阶段二：动态旺度（动态 A 紧贴天干 + 动态 B 同柱生克） (Priority: P1)

静态之后进入动态阶段，天干开始互作用：**动态 A** 只对紧贴三对（年干-月干、月干-日干、日干-时干）判作用，对每对**先判天干五合**（含争合、妒合、合化条件）再判普通生克——合而不化（合绊）只改两个天干旺度、贪合忘生克不再执行普通生克倍率；合化成功则两干废弃原五行改属化神；**动态 B** 遍历四柱做同柱天干与本柱全部藏干的配对运算。

**Why this priority**: 动态阶段是"天干五合归动态、合优先于普通生克"原则的落点，与静态阶段共同构成新的完整计算顺序，直接影响最终旺度。

**Independent Test**: 后端单元测试构造"仅紧贴三对存在五合/生克"的命盘，逐对验证：五合先于生克判定、合绊贪合忘生克、合化改属、争合/妒合取舍；构造隔位天干盘验证不进入动态 A。

**Acceptance Scenarios**:

1. **Given** 一张天干存在五合的命盘，**When** 进入动态 A，**Then** 先对该紧贴对判天干五合，五合成立与否优先于普通生克被判定
2. **Given** 一个紧贴五合合而不化（合绊）的对，**When** 判定该对，**Then** 不改变两干五行、只修改两干旺度，且该对**不再执行普通相生相克倍率**（贪合忘生克）
3. **Given** 一个紧贴五合满足合化条件的对，**When** 判定该对，**Then** 月令与化神条件满足后，两干废弃原五行、以化神五行的旺度替换
4. **Given** 一张存在争合的命盘（妒合与争合同义），**When** 动态 A 第一步判定，**Then** 按争合规则取优先方（力量大者优先、势均力敌双方合绊）
5. **Given** 一个无五合的紧贴天干对，**When** 动态 A 判定，**Then** 执行普通相生相克（判生克权、套倍率公式）
6. **Given** 一对不相邻（非紧贴）的天干，**When** 动态 A 执行，**Then** 不产生任何作用（仅紧贴三对参与）
7. **Given** 任意命盘，**When** 执行动态 B，**Then** 遍历四柱、每柱做同柱天干与本柱**全部藏干**的配对运算
8. **Given** 动态阶段结束，**When** 计算最终旺度，**Then** 修正后天干旺度与阶段一地支藏干度数合并，产出各五行最终旺度

### User Story 3 - 计算步骤展示与测试锚点同步 (Priority: P2)

前端喜忌区"查看计算过程"的步骤顺序重组为新阶段划分（阶段一：原始藏干→地支关系处理→通根→×系数；阶段二：动态 A、动态 B；之后沿用最终旺度/格局/大运/用神）；后端测试命例锚点按新顺序重跑，与 008 结果不一致的锚点逐例记录差异及原因。

**Why this priority**: 步骤展示必须与引擎实际计算顺序一致（008 FR-009）；测试锚点是引擎正确性的验收基准，顺序调整后需重定。

**Independent Test**: 排盘后逐步核对每步中间结果与引擎一致、阶段边界正确；对照测试报告逐例记录新旧顺序差异。

**Acceptance Scenarios**:

1. **Given** 一张已排出的命盘，**When** 查看计算过程，**Then** 步骤按"阶段一静态（原始藏干/地支关系/通根/×系数）→ 阶段二动态（动态 A、动态 B）→ 最终旺度 → 格局 → 大运介入 → 取用神"展示，每步含完整数值轨迹
2. **Given** 步骤中的静态阶段，**When** 查看步骤内容，**Then** 无任何天干五合处理记录，天干保持原始状态
3. **Given** 步骤中的动态 A，**When** 查看相邻对的处理，**Then** 每对标注"先判五合（合化/合绊/贪合忘生克）或无五合走普通生克"的判定路径
4. **Given** 008 期已有命例锚点，**When** 用新顺序重跑，**Then** 与 008 结果一致者保持不变；不一致者逐例记录差异与原因（受顺序调整影响），并重定新锚点
5. **Given** 同一命盘，**When** 任意次重复计算，**Then** 新顺序下结果完全一致（可复现）

### Edge Cases

- **缺时柱（时辰不详）**：动态 A 只有年-月、月-日两对紧贴作用；动态 B 仅对存在的柱配对；静态阶段照常，步骤提示时柱缺失影响。
- **某五行在原局完全缺失**：静态/动态均按 008 规则处理零度五行，如实展示。
- **地支优先级中"半三合""三刑"**：用户优先级列表未单独列出——裁定项见 Assumptions（半三合归三合体系、三刑归"刑"）。
- **合化改变参与干支五行后**：动态 A 合化后的天干以化神五行参与后续生克与最终合并，口径沿用 008（化后参与）。
- **月令被合化**：静态阶段地支处理中月令被合化为他五行时，最终旺度双状态平均口径沿用 008；但合化判定时点随顺序调整移到静态阶段。
- **紧贴三对都无五合**：全部走普通生克（判生克权、套倍率），无对漏判。
- **动态 B 与动态 A 顺序耦合**：同一柱的天干既参与动态 A（与邻柱干）又参与动态 B（与本柱藏干），两者先后与作用对象不重叠（A 跨柱、B 同柱），无冲突。
- **妒合边界**：与争合并见的判例按裁定口径处理（见 Assumptions）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 将旺度计算重组为两个阶段：**阶段一静态旺度**（只处理地支结构，天干保持原始状态、不处理天干五合与天干生克）与**阶段二动态旺度**（处理天干之间作用）。
- **FR-002**: 阶段一 MUST 依次执行：①列出各支原始藏干度数；②按地支论处先后（书原文：辰戌丑未土局＞丑未戌三刑＞三支自刑＞会局＞三合局＞生地半三合＞六冲＞六合＞墓地半三合＞子卯/寅巳申/两支自刑/丑未戌两支相刑＞六害，破排最后）处理地支关系并只修改地支藏干度数；③对修正后藏干做通根运算（连片、距离衰减、月令特权）；④乘月令秉气系数，产出各天干、各藏干的静态分数。
- **FR-003**: 阶段一 MUST 完全不处理天干五合：天干五合属于天干之间的"生克作用体系"，归动态阶段；静态阶段天干不发生互相作用。
- **FR-004**: 阶段二动态 A MUST 只对**紧贴**天干对（年干-月干、月干-日干、日干-时干）判作用；每对内部**优先判定天干五合**，再执行普通天干相生相克（合优先于普通生克）。
- **FR-005**: 天干五合**合而不化（合绊）** MUST 不改变两干五行、只修改两个天干旺度——减力沿用 008 C8 口径（主克者 ×0.8、受克者 ×0.5）；且**贪合忘生克**——该对不再执行普通相生相克倍率。
- **FR-006**: 天干五合**合化成功** MUST 在满足月令、化神条件后，令两个天干废弃原五行、替换为化神五行的旺度。
